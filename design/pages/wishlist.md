# 愿望单页面设计规则

## 1. 页面定位

- 页面名称：愿望单。
- 对应原型：`Screen / Wishlist`。
- 入口路径：`卡牌中心 → 愿望单`。
- 页面只展示已加入愿望单的具体卡牌印刷记录，不显示拥有数量、普通卡数量或闪卡数量。
- 页面快捷操作仅用于取消或重新加入愿望单，不提供普通卡、闪卡拥有数量编辑。

## 2. 页面结构与导航

1. 全站一级导航，当前位于“卡牌中心”。
2. 卡牌中心二级标头，当前选中“愿望单”，说明文字为“管理我的愿望单”。
3. 吸顶面包屑为“卡牌中心 > 愿望单”；“卡牌中心”跳转 Set 列表页，“愿望单”跳转当前页面。
4. 搜索、筛选和排序工具栏。
5. 按系列分组的愿望卡牌列表。
6. 滚动加载状态。

## 3. 搜索、筛选与排序

- 中间搜索框文案为“按卡名搜索愿望单”，只接受卡名关键字，并作为愿望单 list 接口的查询参数；不解析右上角全局搜索框支持的任何语法。
- 卡名关键字变化时从首批结果重新查询并重置滚动位置。
- 系列、语言、颜色、法术力和稀有度筛选与“我的卡牌”保持相同控件尺寸和多选摘要规则，但选项只从当前愿望单记录中生成；其中 UI 的“语言”指卡牌原语言。
- 默认排序为“排序：系列”：系列按发行日期从新到旧，系列内按收藏编号自然序排列。
- 页面不显示“合并不同系列”和“合并不同语言”两个开关。
- 页面右侧不显示全局总数量、“种”数量或收藏数量。
- 系列分组标头末尾不显示愿望卡牌条目数，也不显示“共 X 张，Y 种”的收藏汇总；系列信息与最右侧展开/收起箭头之间仍保留一条自适应宽度的浅色分隔线。整条系列标头均为折叠热区，箭头只提示状态，不是唯一点击入口。

## 4. 卡牌图块

- 卡图尺寸为 244 × 340，横向间隔为 35 px，与其他卡图列表保持一致。
- 卡图下方使用居中的 228 × 24 浅绿色信息条，底色、描边和文字颜色与“我的卡牌”数量条一致，左右各比卡图内收 8 px。
- 信息条左侧显示卡牌固定中文名；右侧设置略大于星形的独立星标热区并显示愿望单星标，不显示 Set、收藏编号、语言和数量。选中态使用金色实心五角星，不使用高亮框。
- 点击卡图进入对应具体印刷版本的可复用卡牌详情页。
- 点击右侧星标热区只切换愿望单状态，必须阻止卡图点击事件，不能同时进入详情页。星标热区不覆盖卡名区域或整条信息栏；点击卡名或信息栏空白处不切换愿望单。
- 模式双面牌仍只占一个卡位，默认显示正面，通过卡牌插画区域右上角的按钮在同一卡位切换正反面，并避开牌名栏及法术力费用标志；正反面共享下方同一个中文卡名和愿望单星标，不得生成两条愿望单记录。翻面按钮与星标热区均阻止卡图点击事件。

## 5. 收藏标记切换

- 后端初次返回的记录均为已加入愿望单状态，使用金色实心五角星。原型中保留一张灰色空心星卡牌，专门表达用户刚取消收藏后、前端暂时保留卡片以便撤销的运行时状态。
- 点击实心星时，前端立即切换为灰色空心星并向后端提交取消请求；灰色空心星表示本次会话中刚取消，可再次点击立即恢复为金色实心星并向后端提交重新加入请求。
- 收藏切换成功后不重新请求列表、不重新排序，也不立即从布局移除卡片，以便用户撤销；请求失败时恢复操作前状态并显示轻量错误提示。
- 就收藏切换造成的状态变化而言，只有重新进入“愿望单”页面时才重新取得后端权威列表；届时已取消收藏的卡片不再出现。当前页面内继续使用前端即时状态。

## 6. 加载与状态

- 页面使用滚动自动加载，不显示传统分页按钮。
- 卡图仅在进入或接近可视区域时加载。
- 空状态显示“愿望单中还没有卡牌”，并提供返回全部卡牌的入口。
- 当前原型中的卡牌和系列条目数只用于表达布局与逻辑，不代表测试数据或最终数据集。

## 7. 当前确认事项

- 已确认愿望单整体结构与“我的卡牌”系列排序页面一致。
- 已确认不显示两个合并开关和页面全局总数量。
- 已确认系列分组标头末尾不显示计数，但保留浅色分隔线和最右侧展开/收起箭头；整条标头均可用于折叠或展开。
- 已确认卡图下方的信息条与“我的卡牌”数量条同色，显示中文卡名和可切换愿望单星标；星标使用略大于符号的右侧独立热区，不把整条信息栏作为按钮。原型以金色实心星为选中态，并保留一张灰色空心星作为刚取消收藏的交互样例。
- 已确认收藏切换采用前端即时更新并请求后端的方式；成功后不刷新列表，取消项保留到重新进入页面，失败时回滚。
- 已确认愿望单列表不提供拥有数量快捷编辑。
