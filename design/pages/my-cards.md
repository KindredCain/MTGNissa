# 卡牌中心 / 我的卡牌

## 1. 页面定位

- 页面名称：我的卡牌。
- 对应原型：`Screen / My Cards`、`Screen / My Cards — Color Sort`、`Screen / My Cards — Mana Sort`。
- 入口路径：`卡牌中心 → 我的卡牌`。
- 只展示普通数量与闪卡数量之和大于零的收藏记录，不建立逐张实体卡档案。

## 2. 页面结构与导航

页面依次包含：

1. 全站一级导航，当前位于“卡牌中心”。
2. 卡牌中心二级标头，保留“全部卡牌 / 我的卡牌 / 愿望单”三个切换入口，当前选中“我的卡牌”，说明文字固定为“管理拥有的卡牌收藏”。
3. 内容面包屑“卡牌中心 > 我的卡牌”。“卡牌中心”跳转到 Set 列表页；“我的卡牌”始终跳转到我的卡牌页的系列排序状态。
4. 搜索、筛选、排序、合并开关和结果数量。
5. 收藏卡牌列表。
6. 滚动加载状态。

收藏卡牌图块只显示完整卡图和收藏数量。卡图使用与其他卡图列表相同的 244 × 340 尺寸，横向间隔为 35 px。卡图下增加居中的 228 × 24 浅绿色数量条，使其左右各比卡图内收 8 px；卡图到所属数量条保持 4 px，数量条到下一行卡图为 10 px，以明确数量条归属于上方卡图。相邻两行卡图的图像间距因此为 38 px。数量条拆分为普通卡与闪卡两个独立步进器，显示为 `− 普通 X ＋ | − 闪卡 Y ＋`。每个加减符号外使用约 18 × 20 的透明独立操作热区，符号自身约 8 × 8；热区只比符号略大，不显示底色、描边或突兀的大按钮。两组之间保留清晰留白和淡色分隔线。不在卡图下重复显示卡名、Set、收藏编号、语言或愿望单状态。点击卡图进入对应具体印刷版本的可复用卡牌详情页。

“我的卡牌”列表的快捷操作仅限普通卡和闪卡拥有数量加减，不显示愿望单星标，也不提供加入或取消愿望单操作。

模式双面牌沿用全部卡牌列表的单卡位翻面设计：只占一个 244 × 340 卡位，默认显示正面，卡牌插画区域右上角的按钮在同一卡位切换正反面，并避开牌名栏及法术力费用标志。正反面共享卡图下方同一组 `− 普通 X ＋ | − 闪卡 Y ＋` 数量操作，不得拆成两条收藏记录或重复统计数量；翻面按钮与数量按钮都必须阻止进入详情页的卡图点击事件。

按系列排序时，每个系列先显示一个系列分组标头。标头依次显示系列缩写、系列名称、发行日期、淡色分隔线、“共 X 张，Y 种”和最右侧的展开/收起箭头。系列缩写不使用按钮框或标签底框，避免连续分组产生过多边框；整条系列标头都是折叠热区，点击系列信息、分隔线空白处或最右箭头的效果相同。

## 3. 数据来源与计数

- App DB 使用 `collection_item JOIN card_print_ref` 取得收藏数量、逻辑卡牌、Set、收藏编号和卡牌原语言分组字段；UI 统一显示为“语言”。
- 仅查询 `normal_quantity + foil_quantity > 0` 的记录；两项都变为零时业务层删除收藏行。
- 名称、颜色、法术力值、稀有度、发行日期及图片等展示信息由 Card DB 按当前批次涉及的标识批量补齐，不进行跨数据库 SQL JOIN。
- 单个具体版本的唯一粒度为逻辑卡牌、Set、收藏编号、语言；普通与闪卡保存在同一条收藏记录的两个数量列中。
- 数量固定分为 `普通 X` 与 `闪卡 Y` 两个步进器；合并后两种数量分别 `SUM`，不能先相加再失去工艺区分。
- 每个步进器左右分别提供减一与加一独立热区，范围略大于符号本身；数量文字、类型分隔线和整条数量栏不触发增减。减一不得使数量低于 0；数量为 0 时减号及其整个热区置灰、进入禁用态且不响应点击。
- 点击数量按钮必须阻止卡图点击事件，不能同时进入卡牌详情页。前端先即时更新对应的 `normal_quantity` 或 `foil_quantity`，同时向后端提交增减请求；请求失败时回滚到操作前数量并显示轻量错误提示。
- 快速增减成功后不重新请求收藏列表、不重新排序，也不从当前布局移除卡片；页面总计和系列分组总计由前端同步重算。
- 两种数量都变为 0 时，后端仍按既有规则移除收藏记录，但当前页面保留该卡片并显示 `普通 0`、`闪卡 0`，两个减号均置灰禁用。只有重新进入“我的卡牌”页面并重新取得后端权威数据后，该卡片才从列表消失。
- 蚀刻闪按现有数据模型计入闪卡数量。
- 页面总计和系列分组总计统一使用“共 X 张，Y 种”：`X = SUM(normal_quantity + foil_quantity)`；`Y` 按 `oracle_id` 去重，表示不同逻辑卡牌种数。少数没有 `oracle_id` 的对象按各自 `scryfall_id` 独立计为一种，避免多个空值被错误合并。

## 4. 搜索与筛选

当前原型提供：

- 卡名关键字搜索。
- 系列下拉筛选，默认“系列：全部”。
- 语言下拉筛选，默认“语言：全部”。
- 颜色筛选。
- 法术力筛选；下拉框文案使用“法术力：全部”，不使用“法术力值”。
- 稀有度筛选。

搜索框和所有下拉框沿用“具体 Set 卡牌列表”的视觉规格：相同的白色底、浅色描边、圆角、内边距、字号和下拉箭头表现。我的卡牌仅额外增加系列和语言两个下拉筛选。

中间搜索框只接受卡名关键字，并作为我的卡牌 list 接口的查询参数；不解析右上角全局搜索框支持的任何语法。关键字变化时从首批结果重新查询并重置滚动位置。

Set 列表、具体 Set 卡牌列表和我的卡牌三处工具栏使用同一尺寸基线：工具栏及控件高度 36 px，搜索框宽度 250 px，控件间距 9 px；搜索文字为 12 px，筛选和排序文字为 11 px。“卡牌中心 > 我的卡牌”面包屑与整条搜索、筛选、排序、合并和计数区域共同吸顶，滚动下面的收藏列表时固定在持久导航下方，不随卡牌内容滚动。

筛选只影响“我的卡牌”范围，不应返回收藏数量为零的卡牌。筛选条件改变后，从首批结果重新查询并重置滚动位置。

### 4.1 多选下拉与选项

系列、语言、颜色、法术力和稀有度筛选都是多选；排序仍是单选。关闭下拉框后的摘要文案统一为：未选择或全选显示“字段：全部”；只选择一项显示具体名称；选择两项及以上显示“字段：已选 N 项”。同一筛选器内多项使用 OR，不同筛选器之间使用 AND。

- 系列：只列出当前收藏数量大于零的 `card_print_ref.set_id` 去重结果，名称由 Card DB 补齐；没有收藏的系列不出现在选项中。
- 语言：此处指卡牌原语言，只列出当前收藏数量大于零的 `card_print_ref.lang` 去重结果，显示名称来自 `scryfall_language`；没有收藏的语言不出现在选项中。
- 颜色：白色、蓝色、黑色、红色、绿色、多色、无色；规则与具体 Set 卡牌列表一致。
- 法术力：0、1、2、3、4、5、6、7+；使用 `scryfall_card.cmc` 归入对应区间。
- 稀有度：普通、非普通、稀有、秘稀、特殊、额外，对应 `common`、`uncommon`、`rare`、`mythic`、`special`、`bonus`。

## 5. 排序规则

支持以下排序：

1. 系列。
2. 颜色。
3. 法术力。
4. 名称。

默认排序项显示为“排序：系列”，采用系列分组展示。排序下拉框与筛选控件之间使用一条加深后的浅灰绿色竖分隔线 `|`；分隔线固定为 1 × 22 px，并在 36 px 工具栏中上下居中：

1. 系列按发行日期从新到旧排列。
2. 每个系列内的卡牌按收藏编号自然序从小到大排列。
3. 收藏编号按自然数语义比较数字片段，并兼容字母、符号和缺失编号。
4. Set 与收藏编号相同的记录再使用语言和稳定标识保证顺序确定。

系列排序的方向是固定规则：系列始终从新到旧，组内收藏编号始终按自然序从小到大。页面不提供正序/倒序切换，也不在排序文案中显示 `↑`、`↓`、“新到旧”等方向说明。

整条系列标头是该分组的折叠控制。点击已展开标头的任意位置会收起该系列的全部卡牌，只保留系列标头；点击已折叠标头的任意位置会恢复该系列卡牌。展开/收起箭头固定放在标头最右侧，用于提示状态，不是唯一点击入口。折叠只改变前端展示状态，不改变查询结果、收藏数量或排序。

按系列排序时，“合并不同系列”不可用并保持关闭。切换到颜色、法术力或名称排序后该开关可用，但默认仍为关闭。“合并不同语言”不受排序方式限制，默认开启。

颜色排序和法术力排序分别对应 `Screen / My Cards — Color Sort` 与 `Screen / My Cards — Mana Sort` 原型。两种排序都使用连续平铺卡图，不显示系列缩写、系列汇总或展开/收起标头；“合并不同系列”开关可用。颜色排序按白、蓝、黑、红、绿、多色、无色的固定顺序，颜色相同按名称和稳定标识排序；法术力排序按 `cmc` 从低到高，数值相同按名称和稳定标识排序。

两个合并开关不占用独立卡片或整行区域，紧凑排列在页面牌张计数左侧。两项均使用滑动开关造型，不使用方框勾选造型；系列排序下“合并不同系列”以禁用关闭状态展示，“合并不同语言”保持可操作且默认开启。

## 6. 合并展示规则

本节所有“语言”均指卡牌原语言。UI 继续使用“合并不同语言”“全部语言”等简洁文案，不显示“原语言”术语。

| 合并不同系列 | 合并不同语言 | 分组键 / 展示单位 |
| --- | --- | --- |
| 关闭 | 关闭 | `scryfall_id`，每个 Set、每种语言分别展示 |
| 开启 | 关闭 | `COALESCE(oracle_id, scryfall_id) + lang`，相同语言跨 Set 汇总 |
| 关闭 | 开启 | `COALESCE(oracle_id, scryfall_id) + set_id + collector_number`，同一 Set 跨语言汇总 |
| 开启 | 开启 | `COALESCE(oracle_id, scryfall_id)`，每个逻辑卡牌展示一张 |

- 没有 `oracle_id` 的对象始终以自身 `scryfall_id` 作为独立分组键，不能把多个空值合并。
- 合并卡用“全部 Set”或“全部语言”表达汇总范围，并允许继续查看其 Set / 语言明细。
- 关闭合并时，同一逻辑卡牌的不同版本仍按当前排序连续、稳定地展示。

## 7. 加载与图片

- 页面不显示传统分页按钮，使用向下滚动自动加载。
- 后端按当前筛选、分组和排序返回稳定游标分页；切换筛选、排序或合并方式会重新开始查询。
- 卡图仅在进入或接近可视区域时加载，避免一次请求大量第三方图片。
- 当前原型中的卡牌、数量和总数只用于表达布局与逻辑，不代表测试数据或最终数据集。
- 就快速增减造成的收藏状态变化而言，操作成功后不得触发列表重查；当前会话继续使用前端即时状态，重新进入页面时才重新读取后端权威收藏列表。滚动加载后续批次仍按原分页规则请求。

## 8. 页面状态

- 首次加载：展示与卡牌图块一致的骨架占位。
- 继续加载：网格底部显示轻量加载提示，不阻断已有内容操作。
- 空结果：明确显示“没有符合条件的收藏卡牌”，并提供清除筛选入口。
- 图片失败：保留图块尺寸，显示统一卡背或图片不可用占位，不影响文字与数量。
- Card DB 补充信息暂时不可用：保留 App DB 中的 Set、收藏编号和语言快照用于诊断展示。
