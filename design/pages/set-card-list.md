# 卡牌中心 / 全部卡牌 / Set 卡牌列表

## 1. 页面定位

- 页面名称：Set 卡牌列表。
- 对应原型：`Screen / Set Card List`。
- 入口路径：`卡牌中心 → 全部卡牌 → Set 列表 → 当前 Set`。
- 页面展示当前 Set、当前选定实体语言下的卡牌印刷记录。
- 本页面属于“全部卡牌”，不统计或展示用户拥有数量、愿望单数量等个人数据。

## 2. 页面结构

页面依次包含：

1. 全站一级导航。
2. 卡牌中心二级标头，当前选中“全部卡牌”。
3. 面包屑。
4. 搜索和筛选工具栏。
5. 纯卡图网格。
6. 无限滚动加载状态。

整体视觉、间距、筛选控件和加载状态应与 Set 列表保持一致。

## 3. 面包屑

左上角保留：

```text
全部卡牌 > Set 名称
```

- “全部卡牌”返回 Set 列表。
- 当前 Set 名称使用中文名称；没有中文名称时回退到英文名称。
- 当前实体语言使用括号紧跟在 Set 名称后，例如 `Secrets of Strixhaven（简体中文）`；不使用独立语言标签。
- 当前语言由 Set 列表的入口确定，不在本页面再次选择。
- 页面不再增加“主体系列”等额外分组标题或导航层级。

## 4. 搜索与筛选

面包屑下方使用单行工具栏。

左侧依次提供：

- 当前 Set 卡名搜索。
- 颜色筛选。
- 法术力值筛选。
- 稀有度筛选。
- 排序。

右侧显示当前查询条件下的卡牌总数，例如“368 张卡牌”。

### 4.1 查询范围

- 页面首次进入时，后端用一次请求返回当前 Set、当前语言下的全部轻量卡牌数据；前端保存完整结果。
- 搜索和筛选作用于前端保存的完整卡牌数据，不是当前已经渲染或已经请求卡图的部分。
- 卡名搜索支持模糊匹配。
- 多个筛选条件可以组合。
- 任一搜索、筛选或排序条件变化后都在前端重新计算结果，清空当前卡图并重置本地滚动位置，不再次请求后端。
- 右侧牌数显示筛选后结果总数，不显示当前已渲染卡图数量。

### 4.2 语言上下文

- 本页面不提供语言筛选框。
- 点击 Set 列表中的具体语言按钮时，进入该语言的卡牌列表。
- 点击 Set 整行、系列名称或系列缩写时，按“简体中文 → 英文”的优先级确定语言。
- 当前语言应成为路由或查询参数的一部分，刷新页面后仍能恢复相同语言上下文。
- 切换语言需要返回 Set 列表选择对应语言按钮，或通过其他明确的上游入口进入；不得在本页混入语言下拉筛选。

## 5. 卡图网格

- 筛选栏下方直接展示卡牌图。
- 只展示当前路由语言对应的卡牌印刷记录。
- 卡图下方不得附加名称、收藏编号、语言、稀有度或说明文字框。
- “全部卡牌”范围不得显示拥有数量、数量调整按钮或愿望单状态。
- 点击卡图进入可复用的卡牌详情页。
- 卡牌详情页不绑定“全部卡牌”专属二级标头，因为详情页也会从我的卡牌、愿望单和卡组进入。

### 5.1 图片来源与尺寸

- 卡图地址按数据字典规定，由 `scryfall_id`、`face_index` 和 `layout` 生成。
- 网格使用完整卡面的 `grid` 规格，目标尺寸为 488 × 680，保持原始宽高比。
- 不使用裁切图代替完整卡面。
- 图片加载失败时显示统一卡背或缺图占位，不显示浏览器破图。
- 原型只需要少量真实卡图样例，用于表达布局与图片规则，不要求准备完整测试数据。

## 6. 排序

- 可选排序项：
  - 收藏编号：升序、降序；默认使用升序。比较方式为自然数字排序，不是普通字符串排序。
  - 法术力值：从低到高、从高到低。
  - 卡牌名称：A 到 Z、Z 到 A。
- 不提供颜色排序。卡牌颜色通常已经随系列收藏编号呈现一定顺序，单独按颜色排序没有足够价值。
- “法术力值排序”只按 `scryfall_card.cmc` 的数值大小排序，不混入颜色顺序。
- 收藏编号不得直接按字符串比较，否则会产生 `1, 10, 2`。应拆分开头连续数字与剩余后缀，先按数字值比较，再按后缀进行稳定比较；例如 `2 < 10 < 10a < 10b`。
- 收藏编号允许跳号，不得假设编号连续；缺少开头数字或无法拆分的特殊编号仍须兼容，统一排在有数字编号之后，再按规范化原值比较。
- 数字部分按任意长度的十进制整数比较，不能依赖固定宽度或可能溢出的数据库整数强制转换。
- 为保证排序结果稳定，主排序值相同时继续按收藏编号升序，再按卡牌记录唯一标识排序。
- 排序作用于当前 Set 的完整查询结果集。
- 切换排序后对已取得的当前 Set 完整轻量数据重新排序，清空当前卡图并重置本地滚动位置。
- 不得加入独立的“图片视图”切换，因为本页面固定为卡图展示。

### 6.1 自然排序与完整 Set 查询

- 收藏编号排序只允许出现在指定 Set、指定语言的卡牌列表，不提供给跨 Set 的语法搜索结果页。
- 进入页面时一次性查询当前 Set、当前语言下的全部轻量卡牌记录；搜索、筛选和排序均在前端完整结果上执行，不为收藏编号排序设计数据库分页表达式或额外排序字段。
- 全量查询只返回排序和后续展示所需的轻量元数据，例如 `scryfall_id`、`collector_number`、`face_index`、`layout` 和卡图地址生成参数；不得在该请求中下载卡图二进制内容。
- 自然比较直接处理原始 `collector_number VARCHAR(64)`，按数字段和文本段交替比较，兼容 `36s`、`64b`、`2X2-332`、`gn147sb` 等形式。
- 当前 Set 卡牌规模有限，因此允许在内存中保存并排序完整结果；排序切换优先复用已有完整结果，不重复请求 Card DB。
- 排序完成后使用稳定唯一标识作为最终平局键，保证同一次结果集中的展示顺序稳定。

## 7. 加载方式

- 页面不显示分页按钮或页码。
- 使用滚轮连续浏览；接近卡图网格底部时自动加载下一批卡牌。
- 滚动加载基于已经全量取得并排好序的轻量结果数组，以本地位置读取下一批，不再向 Card DB 分页查询收藏编号排序结果。
- 浏览器只为当前批次创建卡图节点并请求外部卡图；尚未进入渲染批次的卡牌不得提前请求图片。
- 可以对下一小批卡图做有限预加载，但不得因为已经取得完整元数据而一次性加载当前 Set 的全部外站图片。
- 新批次追加到现有卡图网格；同一批次加载期间不得重复触发。
- 搜索、筛选或排序变化时复用完整数据、重新计算结果并把本地滚动位置重置为开头；只有 Set 或语言变化时才废弃旧数据并重新请求后端。

页面应区分：

- 首次数据获取。
- 继续渲染卡图。
- 空结果。
- 卡图加载失败。
- 首次数据获取失败，可重试。
- 已显示全部结果。

## 8. 响应式与布局

- 桌面原型使用四列卡图。
- 列间距和页面左右留白与 Set 列表保持同一视觉节奏。
- 卡图始终保持完整卡面比例，不能为了填满列宽而拉伸或裁切。
- 视口变窄时减少列数，不压缩卡牌到不可阅读尺寸。

## 9. 当前未确认事项

- 无限滚动每批加载数量和触发阈值尚未确定。
- 窄屏断点及对应列数尚未确定。
- 多面牌在列表中默认展示正面还是当前印刷记录对应牌面，需要结合统一卡图生成规则进一步确认。
