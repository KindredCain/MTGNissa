# 卡牌中心 / 全部卡牌 / Set 卡牌列表

## 1. 页面定位

- 页面名称：Set 卡牌列表。
- 对应原型：普通 Set 使用 `Screen / Set Card List`，Token Set 使用 `Screen / Token Set Card List`。不同桌面宽度由本页响应式规则处理，不复制独立尺寸画板。
- 入口路径：`卡牌中心 → 全部卡牌 → Set 列表 → 当前 Set`。
- 普通 Set 展示当前 Set、当前选定卡牌原语言下的卡牌印刷记录，UI 统一将卡牌原语言显示为“语言”；Token Set 直接展示该 Set 的全部 `mtgnissa_token` 记录，不指定或展示语言。
- 本页面属于“全部卡牌”，不统计或展示用户拥有数量、愿望单数量等个人数据。

## 2. 页面结构

页面依次包含：

1. 全站一级导航。
2. 卡牌中心二级标头，当前选中“全部卡牌”，说明文字固定为“查看全部卡牌”。
3. 面包屑。
4. 普通 Set 的搜索、筛选、排序工具栏及结果总数；Token Set 仅显示结果总数，不显示搜索、筛选和排序控件。
5. 纯卡图网格。
6. 无限滚动加载状态。

普通 Set 的整体视觉、间距、筛选控件和加载状态应与 Set 列表保持一致；Token Set 的结果区沿用语法搜索结果页的总数与纯卡图网格布局。

面包屑与搜索、筛选、排序工具栏组成吸顶区域。滚动卡牌网格时，两者都固定在持久导航下方，不得随卡牌列表滚出视口。工具栏及控件高度为 36 px，搜索框宽度为 250 px，控件间距为 9 px；搜索文字使用 12 px，筛选和排序文字使用 11 px。

## 3. 面包屑

左上角保留：

```text
卡牌中心 > 全部卡牌 > Set 名称（语言）
```

- “卡牌中心”和“全部卡牌”均返回 Set 列表。
- 当前 Set 名称使用中文名称；没有中文名称时回退到英文名称。
- 当前卡牌原语言使用 `scryfall_language.display_name`，并以括号紧跟在 Set 名称后，例如默认数据下显示 `Secrets of Strixhaven（简中）`；UI 不暴露“原语言”字样，也不使用独立语言标签。
- 当前语言由 Set 列表的入口确定，不在本页面再次选择。
- Token Set 的面包屑只显示 Set 名称，不附加语言括号。
- 页面不再增加“主体系列”等额外分组标题或导航层级。

## 4. 搜索与筛选

本节搜索、筛选、语言上下文及工具栏控件仅适用于普通 Set。Token Set 不接受名称关键字、语言、筛选或用户排序条件，具体规则见第 9 节。

面包屑下方使用单行工具栏。

左侧依次提供：

- 当前 Set 卡名关键字搜索。
- 颜色筛选。
- 法术力筛选；下拉框文案使用“法术力：全部”，不使用“法术力值”。
- 稀有度筛选。
- 排序。

右侧显示当前查询条件下的卡牌总数，例如“368 张卡牌”。

### 4.1 查询范围

- 页面首次进入时，普通 Set 由后端用一次 list 请求返回当前 Set、当前语言下的全部轻量卡牌数据，前端保存完整结果。
- 中间搜索框只接受卡名关键字，不解析 `otag:`、冒号操作符、布尔表达式或其他查询语法。关键字作为当前 Set 卡牌 list 接口的查询参数。
- 卡名关键字匹配当前 Set、当前语言范围内 `mtgnissa_card_printing.printed_name`；列表以 `mtgnissa_card_printing -> mtgnissa_card -> 翻译` 为读取链路。
- 卡名关键字变化并提交后，废弃旧的完整结果并重新请求 list 接口；接口一次返回当前 Set、当前语言、当前卡名关键字下的全部轻量卡牌数据。
- 颜色、法术力和稀有度筛选以及排序作用于当前 list 接口已返回的完整结果，不是当前已经渲染或已经请求卡图的部分。
- 卡名搜索支持不区分大小写的关键字模糊匹配。
- 多个筛选条件可以组合。
- 卡名关键字变化时重新请求 list 接口；筛选或排序变化时复用当前完整结果在前端重新计算。两类变化都清空当前卡图并重置本地滚动位置。
- 右侧牌数显示筛选后结果总数，不显示当前已渲染卡图数量。

### 4.2 语言上下文（卡牌原语言）

- 本页面不提供语言筛选框。
- 点击 Set 列表中的具体语言按钮时，进入该语言的卡牌列表。
- 点击普通 Set 整行、系列名称或系列缩写时，使用 Set 列表接口返回的 `default_language` 进入对应语言的卡牌列表；该值固定为响应中 `languages` 数组从左到右第一项 `available = true` 的语言，不使用“简体中文 → 英文”或其他前端隐藏优先级。普通 Set 的 `default_language = null` 时该行不提供跳转目标。
- 当前语言应成为路由或查询参数的一部分，刷新页面后仍能恢复相同语言上下文。
- 切换语言需要返回 Set 列表选择对应语言按钮，或通过其他明确的上游入口进入；不得在本页混入语言下拉筛选。
- 上述语言规则只适用于普通 Set；Token Set 从 Set 行直接进入，不携带语言参数，也不建立语言切换入口。

### 4.3 多选下拉与选项

颜色、法术力和稀有度筛选都是多选；排序仍是单选。关闭下拉框后的摘要文案统一为：未选择或全选显示“字段：全部”；只选择一项显示具体名称；选择两项及以上显示“字段：已选 N 项”。同一筛选器内多项使用 OR，不同筛选器之间使用 AND。

打开多选下拉框时，以当前已提交条件初始化一份临时选择；下拉框内勾选只更新临时选择，不立即筛选卡图。点击下拉框外任意区域时立即关闭并提交最终选择；只有选择发生变化时，才在关闭完成后对已取得的当前 Set 完整轻量结果执行一次筛选、重置本地滚动位置和卡图渲染批次，不重新请求 Card DB。选择未变化时关闭不重复计算。下拉框不提供“确定”或“取消”按钮。对应展开态见 `.pen` 中的 `Prototype / Multi-select Filter Dropdown — Open`。

- 颜色：白色、蓝色、黑色、红色、绿色、多色、无色。基础颜色来自 `scryfall_color`；多色表示 `colors_mask` 含两个及以上颜色，无色表示颜色集合为空。
- 法术力：0、1、2、3、4、5、6、7、8+；0 至 7 分别匹配关联的 `mtgnissa_card.cmc` 等于对应数值，8+ 匹配 `cmc >= 8`。
- 稀有度：铁、银、金、秘稀、特殊、额外，对应接口原值 `common`、`uncommon`、`rare`、`mythic`、`special`、`bonus`；铁、银、金只作为界面文案，不改变接口或数据库枚举。

## 5. 卡图网格

- 筛选栏下方直接展示卡牌图。
- 普通 Set 只展示当前路由语言对应的卡牌印刷记录；Token Set 展示该 Set 的全部 Token 记录。
- 卡图下方不得附加名称、收藏编号、语言、稀有度或说明文字框。
- “全部卡牌”范围不得显示拥有数量、普通卡/闪卡数量调整按钮、愿望单状态或愿望单切换按钮。
- 普通 Set 以当前列表项的 `printing_uuid` 进入可复用的卡牌详情页；双面或多牌面统一使用主牌面的语言印刷 UUID。Token Set 不提供该跳转。
- 卡图点击是普通 Set 列表唯一的卡牌级操作；收藏数量和愿望单只能进入卡牌详情页后管理。Token Set 的卡图只供浏览，不进入普通卡牌详情，不提供收藏、愿望单或卡组操作。
- 卡牌详情页不绑定“全部卡牌”专属二级标头，因为详情页也会从我的卡牌、愿望单和卡组进入。
- 所有能够取得不同正反面卡图的双面或多牌面印刷均复用同一卡位翻面逻辑，不区分模式双面、转化式双面或其他双面 `layout`。在网格中仍是一个列表结果，只占一个 244 × 340 标准卡位；默认显示正面，不并排展示多个牌面。多个规则牌面共用同一张正面卡图的单面布局不显示翻面按钮。
- 上述卡牌的插画区域右上角叠加圆形翻面按钮，避开牌名栏及法术力费用标志。点击按钮只在当前卡位切换正面与背面，必须阻止卡图点击事件，不进入详情页、不改变排序，也不新增另一条结果；点击卡图的其他区域仍进入同一个具体印刷版本详情页。
- 普通卡牌正反面图片属于同一个具体印刷版本。语言印刷行缺少图片 ID 时，仅卡图来源回退关联的 `mtgnissa_card.scryfall_id`；列表项的业务标识、语言、详情跳转及后续操作仍对应原印刷版本，不因图片回退而改变。卡图 URL 的解析与拼接由后端完成，列表项直接消费返回的 `images.front_url`、`back_url` 和 `has_distinct_back`；前端不得根据 `scryfall_id`、`face_index` 或 `layout` 自行生成地址。翻面后的牌面状态仅属于当前前端列表项，不改变卡牌语言、收藏编号或后端数据。

### 5.1 图片来源与尺寸

- 卡图地址由后端按数据字典规则解析并通过 API 返回；前端直接使用 `CardSummaryDTO.images.front_url` 和 `back_url`，并以 `has_distinct_back` 判断是否显示翻面控件。URL 为空时使用统一缺图占位，不在前端补拼地址。
- 网格使用完整卡面的 Scryfall `normal` 规格；已通过官方卡牌 API 返回的图片地址核对，实际资源尺寸为 488 × 680。
- 桌面原型按资源尺寸的 50% 显示为 244 × 340，保持精确宽高比；五列卡图横向间隔为 35 px，纯卡图列表的纵向图像间距为 20 px。
- 不使用裁切图代替完整卡面。
- 图片加载失败时显示统一卡背或缺图占位，不显示浏览器破图。
- 原型只需要少量真实卡图样例，用于表达布局与图片规则，不要求准备完整测试数据。

## 6. 排序

本节排序控件及客户端排序规则仅适用于普通 Set；Token Set 不提供排序入口，固定顺序见第 9 节。

- 排序下拉框与前面的筛选控件之间使用一条加深后的浅灰绿色竖分隔线 `|`。分隔线固定为 1 × 22 px，并在 36 px 工具栏中上下居中。
- 可选排序项：
  - 收藏编号：升序、降序；默认使用升序。比较方式为自然数字排序，不是普通字符串排序。
  - 法术力值：从低到高、从高到低。
  - 卡牌名称：A 到 Z、Z 到 A。
- 不提供颜色排序。卡牌颜色通常已经随系列收藏编号呈现一定顺序，单独按颜色排序没有足够价值。
- “法术力值排序”只按关联的 `mtgnissa_card.cmc` 数值大小排序，不混入颜色顺序。
- 收藏编号不得直接按字符串比较，否则会产生 `1, 10, 2`。应拆分开头连续数字与剩余后缀，先按数字值比较，再按后缀进行稳定比较；例如 `2 < 10 < 10a < 10b`。
- 收藏编号允许跳号，不得假设编号连续；缺少开头数字或无法拆分的特殊编号仍须兼容，统一排在有数字编号之后，再按规范化原值比较。
- 数字部分按任意长度的十进制整数比较，不能依赖固定宽度或可能溢出的数据库整数强制转换。
- 为保证排序结果稳定，主排序值相同时继续按收藏编号升序，再按 `printing_uuid` 升序排序。
- 排序作用于当前 Set 的完整查询结果集。
- 切换排序后对已取得的当前 Set 完整轻量数据重新排序，清空当前卡图并重置本地滚动位置。
- 不得加入独立的“图片视图”切换，因为本页面固定为卡图展示。

### 6.1 自然排序与完整 Set 查询

- 收藏编号排序只允许出现在指定 Set、指定语言的卡牌列表，不提供给跨 Set 的语法搜索结果页。
- 进入页面或卡名关键字变化时，一次性查询当前 Set、当前语言和当前关键字下的全部轻量卡牌记录；筛选和排序在该完整结果上执行，不为收藏编号排序设计数据库分页表达式或额外排序字段。
- 全量查询只返回排序和后续展示所需的轻量元数据，例如 `printing_uuid`、`collector_number`、`layout` 以及后端已经解析完成的 `images.front_url`、`images.back_url`、`images.has_distinct_back`；不得在该请求中下载卡图二进制内容，前端也不得再次生成卡图地址。
- 自然比较直接处理原始 `collector_number VARCHAR(64)`，按数字段和文本段交替比较，兼容 `36s`、`64b`、`2X2-332`、`gn147sb` 等形式。
- 当前 Set 卡牌规模有限，因此允许在内存中保存并排序当前关键字对应的完整结果；筛选或排序切换复用已有结果，不重复请求 Card DB，只有卡名关键字、Set 或语言变化才重新请求 list 接口。
- 排序完成后使用 `printing_uuid` 作为最终平局键，保证同一次结果集中的展示顺序稳定。

## 7. 加载方式

- 页面不显示分页按钮或页码。
- 使用滚轮连续浏览；接近卡图网格底部时自动加载下一批卡牌。
- 滚动加载基于已经全量取得并排好序的轻量结果数组，以本地位置读取下一批，不再向 Card DB 分页查询收藏编号排序结果。
- 浏览器只为当前批次创建卡图节点并请求外部卡图；尚未进入渲染批次的卡牌不得提前请求图片。
- 可以对下一小批卡图做有限预加载，但不得因为已经取得完整元数据而一次性加载当前 Set 的全部外站图片。
- 新批次追加到现有卡图网格；同一批次加载期间不得重复触发。
- 卡名关键字变化时废弃旧数据并重新请求 list 接口；筛选或排序变化时复用完整数据重新计算。卡名关键字、Set 或语言任一变化都重置本地滚动位置。

页面应区分：

- 首次数据获取。
- 继续渲染卡图。
- 空结果时卡图网格直接为空，不显示专用空状态、说明文字或清空条件入口。
- 卡图加载失败。
- 首次数据获取或后续处理失败时打开全局统一错误弹窗，不在列表内增加错误卡片或重试入口。
- 已显示全部结果。
- 前端单批渲染数量和接近底部时的触发阈值，在前端开发及联调时根据图片加载压力和页面渲染表现确定，并保留为可调参数；后端仍一次返回完整轻量结果，不得因此改成分页按钮或一次性加载全部卡图。

## 8. 响应式与布局

- 1440 × 900 主原型使用五列卡图，每张卡图固定为 244 × 340，横向间隔为 35 px，纵向图像间距为 20 px。
- 前端根据内容区实际可用宽度自动决定列数；1366 px 与 1280 px 宽度应自然降为四列。降列时保持卡图尺寸与 35 px 固定间隔，网格左对齐，剩余宽度留在行尾，不通过放大间隔或等比缩放填满一行。
- 具体 Set 卡牌列表、搜索结果卡牌列表和我的卡牌列表共用这套卡图尺寸与间隔基线；我的卡牌只额外增加卡图下方的数量条。
- 卡图始终保持完整卡面比例，不能为了填满列宽而拉伸或裁切。
- 视口在 1280 px 及以上时按可用宽度减少列数，不压缩卡牌到不可阅读尺寸。页面主体固定最小布局宽度 1280 px；视口低于 1280 px 时保持 1280 px 的四列布局，由浏览器提供整页横向滚动，不继续减少列数或缩放页面。视口高度低于 720 px 时使用浏览器正常纵向页面滚动。

## 9. Token Set 浏览模式

- 直接按当前 Token Set 的 `set_code` 读取 `mtgnissa_token`，不关联 `mtgnissa_card_printing`，不指定语言，不进入全局语法搜索流程。
- 页面保留全站导航、“全部卡牌”二级标头、无语言括号的 Set 面包屑、结果总数和纯卡图网格；面包屑及总数区域吸顶。内容区不提供名称搜索、筛选或排序控件，也不预留它们的空白位置。
- 一次取得该 Token Set 的完整轻量记录，后端按具体印刷组织卡面。同一印刷中共享非空 `scryfall_id` 的双面或多牌面 Token 合为一个列表项，按 `face_index` 组织正反面，取主牌面作为默认展示；不按 `oracle_id` 合并不同印刷。缺少公开 ID 且无法可靠配对的记录按各自 `uuid` 保留，使用缺图占位，不将空 ID 归成同一项。
- 列表项固定按主牌面收藏编号自然升序、主牌面 `uuid` 升序兜底返回，前端保持该顺序。具备不同正反面卡图的 Token 沿用普通双面牌交互：只占一个标准卡位，在原位翻面，不把正反面分别计为两张结果。
- 只按本地渲染批次逐步显示卡图并按需加载图片，沿用第 7 节的滚动加载方式；结果总数表示合并多牌面后的完整印刷列表项数量。Set 索引行的 `mtgnissa_set.card_count` 仍保留数据字典的导入卡面数口径，不改变原始计数。
- 卡图只供浏览，不跳转普通卡牌详情，不提供收藏、愿望单、卡组或语言入口。具备不同正反面卡图时可在原卡位翻面；缺少 `scryfall_id` 或图片不可用时显示统一缺图占位。
- Token 直接使用自身卡面信息，不套用普通卡 `printed_name`、`cmc`、`rarity` 或语言印刷行的搜索筛选规则。
