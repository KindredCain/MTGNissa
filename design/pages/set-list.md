# 卡牌中心 / 全部卡牌 / Set 列表

## 1. 页面定位

- 页面名称：Set 列表。
- 对应原型：`Screen / All Cards — Set Index`。
- 入口路径：`卡牌中心 → 全部卡牌`。
- “全部卡牌”的默认落地页就是 Set 列表，不先展示全量卡牌网格。
- 点击某个 Set 后进入该 Set 的全卡牌列表。
- 本页面只描述全部卡牌范围，不统计或展示用户拥有数量、愿望单数量等个人数据。

## 2. 导航层级

页面顶部固定使用两层结构：

1. 一级导航：网站标题，以及“卡牌中心 / 卡组 / 操作日志”。
2. 卡牌中心二级标头：左侧显示当前二级菜单“全部卡牌”，右侧提供“全部卡牌 / 我的卡牌 / 愿望单”切换。

正文中不得再重复出现“全部卡牌 / 我的卡牌 / 愿望单”，也不增加“按系列”等额外菜单层级。

补充约定：卡组和操作日志没有二级菜单列表；卡牌详情为跨入口复用页面，不固定显示卡牌中心二级标头。

## 3. 数据来源

### 3.1 Set 基础信息

Set 数据来自 `scryfall_set`：

- `set_id`：Set 唯一标识。
- `code`：系列缩写。
- `name`：系列英文名称。
- `set_type`：系列类型。

中文系列名称通过 `zhs_set.set_id` 逻辑关联取得；没有中文名称时回退到 `scryfall_set.name`。

卡牌数量、发行日期和可用语言从该 Set 关联的 `scryfall_card` 记录聚合得到，不在页面中使用个人数据库统计。

### 3.2 系列类型

- 类型筛选值来自 `scryfall_set.set_type`。
- `set_type` 是数据源提供的原始字符串，不在前端维护另一套系列类型枚举。
- 页面只保留“系列类型”下拉筛选。
- 不再同时提供“扩展系列 / 核心系列 / 指挥官 / 选集 / 特殊系列”等快捷分类栏，避免与类型下拉重复，也避免引入数据字典中没有定义的自建分组。

### 3.3 可用语言

全量语言枚举来自 `scryfall_language`，不得在前端硬编码语言列表。

某个 Set 的可用语言按以下规则派生：

1. 查询 `scryfall_language`，得到全量语言代码和名称。
2. 按当前 `set_id` 对 `scryfall_card.lang` 去重，得到该 Set 实际存在的语言。
3. 将全量语言与 Set 实际语言做左连接。
4. 存在对应卡牌记录的语言正常显示；不存在的语言置灰。

顶部语言下拉框同样从 `scryfall_language` 生成选项。选择语言后，只展示至少存在一张该语言卡牌的 Set。

语言状态同时承担导航作用：

- 正常显示的语言按钮可以点击，进入该 Set 对应语言的卡牌列表。
- 置灰语言不可点击。
- 点击系列整行、系列名称或系列缩写时，默认语言按“简体中文 → 英文”的优先级选择。
- 简体中文存在时进入简体中文卡牌列表；否则进入英文卡牌列表。

原型中的具体语言状态只是规则样例，不代表真实完整数据。

## 4. 系列标识

- Set 列表不显示系列图标，只使用系列名称和系列缩写识别系列。
- 页面不得为了系列图标额外下载、缓存或热链 Scryfall SVG 资源。
- 系列缩写直接使用 `scryfall_set.code`，不再承担图标加载失败时的替代占位逻辑。

## 5. 查询与筛选

页面提供以下查询条件：

- 全库系列缩写模糊查询。
- 语言筛选。
- 系列类型筛选。
- 排序。

### 5.1 全库系列缩写查询

- 查询目标是完整的 `scryfall_set` 数据集，不是浏览器中已经加载的行。
- 对 `code` 执行不区分大小写的模糊包含匹配。
- 例如输入 `so` 可以匹配 `SOS`、`SOA`、`PSOS` 等缩写。
- 输入变化后重新执行后端全库查询，清空当前已加载行并重置分页游标。
- 清空查询后恢复完整 Set 结果集。

### 5.2 筛选组合

- 系列缩写、语言和系列类型条件可以组合。
- 任一查询条件变化后都重新执行后端查询，并重置分页游标和滚动加载状态。
- 筛选控件只保留一套，不在正文其他位置重复提供等价入口。

## 6. 排序

- 可选排序项：
  - 发行日期：新到旧、旧到新；默认使用新到旧。
  - 系列名称：A 到 Z、Z 到 A。
  - 系列缩写：A 到 Z、Z 到 A。
  - 卡牌数量：多到少、少到多。
- 不提供 Block/Group 排序，因为当前 `scryfall_set` 数据模型没有对应字段。
- 排序由后端作用于完整查询结果集，而不是当前已加载部分。
- 切换排序后重新查询，清空当前行并重置分页游标。

## 7. 列表字段

每行至少展示：

- 系列名称。
- 系列缩写。
- 系列类型。
- 卡牌数量。
- 发行日期。
- 全量语言枚举及其可用/置灰状态。

点击行为：

- 点击可用语言按钮：进入该 Set 对应语言的卡牌列表。
- 点击系列名称、缩写或整行：按“简体中文 → 英文”的优先级进入卡牌列表。

## 8. 加载方式

- 页面不显示分页按钮和页码。
- Set 列表使用后端分页查询，因为每行需要关联或聚合系列中文名、卡牌数量、发行日期和可用语言等多表数据，不一次性返回全部 Set。
- 使用滚轮连续浏览；接近列表底部时自动请求下一批数据。
- 后端使用当前搜索、筛选和排序条件对应的稳定游标分页，不使用页面按钮或固定页码。
- 同一游标请求期间不得重复发起加载；成功后把新行追加到当前列表。
- 搜索、筛选或排序变化时废弃旧结果和旧游标，从第一批重新查询。
- 已无更多结果时停止观察底部触发器，并显示结束状态。

页面应区分以下状态：

- 首次加载。
- 继续加载。
- 空结果。
- 加载失败，可重试。
- 已加载全部结果。

## 9. 当前未确认事项

- `scryfall_set` 当前数据字典没有父 Set 字段。Scryfall 风格的父子 Set 缩进在数据来源补充前只作为视觉参考，不作为已确认的实现规则。
- 全量语言的固定展示顺序尚未在数据字典中定义；实现前需要确定按官方顺序、产品顺序或代码排序。
- 后端每批返回数量和滚动触发阈值尚未确定。
- 如果某个 Set 同时不存在简体中文和英文，点击整行时的兜底语言选择尚未确定。
