# 卡牌中心 / 全部卡牌 / 语法搜索结果

## 1. 页面定位

- 页面名称：卡牌语法搜索结果。
- 对应原型：`Screen / Card Search Results`、`Screen / Card Search Results — Empty`。
- 页面复用 Set 卡牌列表的导航、吸顶面包屑、结果总数、纯卡图网格和无限滚动视觉风格，但不复用内容区搜索、筛选或排序控件。
- 页面入口包括全站右上角搜索框，以及卡牌详情“功能标签”中的具体标签。
- 查询在本地卡牌数据和功能标签数据上执行，不把用户查询逐次转发给 Scryfall。
- 首版语法范围以功能需求第 2.2 节及其引入的[搜索语法支持矩阵](../../docs/search-syntax-support.md)为共同基线；矩阵当前保留项均为首版必须实现和验收的范围。

## 2. 全局搜索入口

- 全站右上角搜索框同时支持普通卡名搜索和语法搜索，提示文案为“搜索卡牌或输入语法…”。搜索框右侧固定显示一个独立的小型“？”语法帮助按钮，不把按钮嵌入输入框的文字区域。
- 语法帮助按钮使用 28 × 28 px 圆形点击热区，默认背景和描边透明，仅显示 17 px 的低强调度圆形问号线性图标；不得使用带文字问号的方形描边按钮。鼠标悬浮或键盘聚焦时才显示轻微的导航次级底色，保持与搜索图标一致的线性视觉重量。
- “？”按钮直接在新浏览器标签页打开 Scryfall 官方语法说明 `https://scryfall.com/docs/syntax`，不经过本系统中转页；按钮需要提供“查看搜索语法帮助”的可访问名称，并使用 `noopener noreferrer` 隔离外链页面。
- 提交后进入 `卡牌中心 → 全部卡牌 → 语法搜索结果`，并把有效查询写入路由参数，保证刷新、前进后退和复制链接后结果不变。
- 输入只有普通文本且不包含语法操作符时，按卡名模糊查询处理。
- 搜索语法的操作符写法、引号、比较符和布尔组合参照 Scryfall 官方语法说明；实际字段、别名、比较符和值域严格以搜索语法支持矩阵为准，本系统只执行能够完整识别的首版语法表达式。
- 输入能够被当前语法解析器完整识别时执行语法查询；只要不能完整匹配当前支持的语法，无论是否包含冒号、引号、括号或类似操作符的字符，都将完整原文作为卡牌名称关键字执行模糊查询。本入口不存在“语法错误”页面或错误提示。
- 语法解析只属于右上角全局搜索框和功能标签跳转；列表内容区的中间搜索框不得进入本解析流程。

## 3. 功能标签语法

- 功能标签的规范操作符为 `otag:`。
- 兼容 Scryfall 常用别名 `oracletag:` 和 `function:`；解析后统一规范化为 `otag:`。
- 用户输入可使用 `otag:ramp`、`function:tutor`、`otag:"mana rock"`；后端执行时统一规范化为带双引号的 `otag:` 查询，例如 `otag:"ramp"`、`otag:"tutor"`、`otag:"mana rock"`。
- 标签匹配链为 `mtgnissa_card.oracle_id → oracle_tag_mapping.oracle_id → oracle_tag.tag_id`。
- 标签名称从 `oracle_tag.label` 匹配；后续如要完整支持 Scryfall slug，应在数据模型中保留 `slug`，不能仅靠不可逆字符串猜测。
- 多个空格分隔条件、`OR` 和括号组合遵循功能需求第 2.2 节及搜索语法支持矩阵；否定以及其他不在首版支持范围内或无法完整识别的表达式不报错，整体回退为名称模糊查询。

## 4. 标签点击跳转

- 卡牌详情的“功能标签”页签按钮只切换内容，不触发查询或页面跳转。
- 页签切换后，具体功能标签直接显示卡牌详情接口返回的 `oracle_tags[].query`。点击标签时将该展示字符串原样作为 `GET /api/v1/search` 的 `q` 参数提交，并进入本页面。
- 标签查询的 `otag:` 前缀、双引号及转义均由后端生成；前端不得自行拼接、增删引号、规范化或再次转义。展示值与实际提交值必须完全相同。
- 标签跳转与用户手工输入相同语法必须得到相同查询结果、路由和面包屑。

## 5. 面包屑

搜索结果页的面包屑固定为：

```text
卡牌中心 > 全部卡牌 > 对应搜索条件的语法
```

- “卡牌中心”和“全部卡牌”均返回 Set 列表页。
- 面包屑末段显示本次实际执行的规范化语法，或回退为名称模糊查询时的完整查询原文，例如 `otag:"ramp"`。
- 面包屑只显示查询，不额外插入“搜索结果”等中间层级。
- 查询过长时单行截断并提供完整查询提示；复制链接和路由中仍保存完整查询。

## 6. 结果列表

- 结果区复用 Set 卡牌列表的五列纯卡图网格：卡图 244 × 340，横向间隔为 35 px，纵向图像间距为 20 px；不在卡图下增加说明框。
- 能够取得不同正反面卡图的双面或多牌面印刷均复用 Set 卡牌列表的单卡位翻面交互：一个结果只占一个标准卡位，默认显示正面，卡牌插画区域右上角的按钮在当前卡位切换正反面并避开法术力费用标志；不得把多个牌面并排显示或计为多个结果。多个规则牌面共用同一张正面卡图的单面布局不显示翻面按钮。
- 本页面属于“全部卡牌”范围，只提供浏览和卡牌详情入口，不显示拥有数量、普通卡/闪卡数量调整按钮、愿望单状态或愿望单切换按钮。
- 结果页内容区不显示名称搜索框、筛选控件或排序控件。修改查询只能通过右上角全局搜索框重新提交，或从卡牌详情中的具体功能标签重新进入本页面。
- 右侧显示按 `oracle_id` 去重后的完整查询结果总数，不显示当前已加载数量；界面仍使用“张卡牌”的用户口径，不显示“逻辑卡”字样。
- 使用无限滚动，不显示分页按钮。
- 查询变化时清空已加载结果并重置游标。
- 合法语法查询或名称模糊查询没有匹配项时，页面保持正常搜索结果布局：结果总数显示“0 张卡牌”，卡图网格为空，不显示错误、警告、重试按钮或额外的空状态说明。
- 语法搜索固定以 `oracle_id` 为结果单位，同一 `oracle_id` 只返回一项，不展开不同 Set 或印刷记录，也不建立具体印刷语言上下文。
- 搜索结果直接使用 `mtgnissa_card -> 翻译、卡面展开表或 Oracle 数据` 链路。后端为每个命中的 `oracle_id` 在其全部 `mtgnissa_card` 记录中按 `scryfall_id` 升序选择代表印刷，再取该印刷的主牌面：普通单面牌取 `face_index = -1`，多牌面牌取 `face_index = 0`。主牌面作为名称、排序及摘要字段的基准，并提供完整正反面图片与详情跳转目标；不得在共享同一 `scryfall_id` 的多个卡面之间任意取行。不按发行日期选择最新版本；前端直接消费后端结果。
- 点击结果卡图时，使用后端返回的 `printing_uuid` 进入代表印刷对应的语言版本详情；双面或多牌面使用主牌面语言印刷 UUID。该入口标识由后端在选定代表基础印刷后解析，不将语言印刷表用于搜索命中计算，也不改变直接从 `mtgnissa_card` 搜索的链路。详情页仍可通过“其他系列版本”和语言选择切换到其他印刷版本。

## 7. 固定结果顺序

- 页面不提供排序下拉框，也不接受来自内容区的排序交互；语法搜索结果跨越多个 Set，因此不提供收藏编号或发行日期排序。
- 后端必须先按 `oracle_id` 去重，再按英文卡名不区分大小写 A–Z 排序；同名时按 `oracle_id` 升序兜底。代表 `mtgnissa_card` 记录的系列和发行日期不得参与结果顺序计算。
- 搜索结果使用服务端游标持续读取；游标必须同时编码规范化后的英文卡名排序值与 `oracle_id` 位置，以延续“英文卡名不区分大小写 A–Z、同名按 `oracle_id` 升序”的完整顺序。不能一次性把跨 Set 的完整搜索结果发送给浏览器；游标分页过程中同一 `oracle_id` 不得重复或遗漏。

## 8. 首版语法范围

- 首版支持范围已经由功能需求第 2.2 节和[搜索语法支持矩阵](../../docs/search-syntax-support.md)共同形成基线，不再留待开发阶段决定。矩阵当前保留的全部关键字、别名、比较符和值域都必须实现和验收，调整范围时必须同步修改需求与矩阵。
- 首版支持普通名称与 `name:`，颜色与颜色标识、卡牌类别、`keyword:`/`kw:`、`mv:`/`manavalue:`、力量/防御力/忠诚值、多面牌布局、`is:spell`/`is:permanent`/`is:historic`、稀有度、系列、显式 `OR`、圆括号和空格隐式 `AND`。同时支持卡牌详情功能标签使用的 `otag:`、`oracletag:` 和 `function:`。
- Card Text 不支持 `fo:`、`o:` 或 `oracle:`；Mana Costs 不支持 `m:` 或 `mana:`。语言、收藏编号、正则表达式、显示或排序控制以及矩阵未列出的其他 Scryfall 写法也不属于首版语法范围。出现任一未支持写法时，完整原文回退为卡名模糊查询，不得执行部分语法或显示语法错误。
- 支持双引号及规定的转义，不支持条件或分组否定。字段、别名、值、比较符、数值和多牌面规则以功能需求第 2.2 节及搜索语法支持矩阵为共同业务口径。
- 页面通过全局搜索框右侧的“？”按钮外链 Scryfall 官方语法说明。该链接用于表达形式参考，不代表本系统兼容该页面的全部操作符。
