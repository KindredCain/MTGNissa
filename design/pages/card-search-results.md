# 卡牌中心 / 全部卡牌 / 语法搜索结果

## 1. 页面定位

- 页面名称：卡牌语法搜索结果。
- 本页面后续实现，复用 Set 卡牌列表的搜索、筛选、卡图网格和无限滚动视觉风格。
- 页面入口包括全站右上角搜索框，以及卡牌详情“功能标签”中的具体标签。
- 查询在本地卡牌数据和功能标签数据上执行，不把用户查询逐次转发给 Scryfall。

## 2. 全局搜索入口

- 全站右上角搜索框同时支持普通卡名搜索和语法搜索，提示文案为“搜索卡牌或输入语法…”。
- 提交后进入 `卡牌中心 → 全部卡牌 → 语法搜索结果`，并把有效查询写入路由参数，保证刷新、前进后退和复制链接后结果不变。
- 输入只有普通文本且不包含语法操作符时，按卡名模糊查询处理。
- 输入包含已支持的操作符时按语法解析；语法错误必须显示错误位置和原因，不得静默当作普通卡名。

## 3. 功能标签语法

- 功能标签的规范操作符为 `otag:`。
- 兼容 Scryfall 常用别名 `oracletag:` 和 `function:`；解析后统一规范化为 `otag:`。
- 示例：`otag:ramp`、`function:tutor`、`otag:"mana rock"`。
- 标签匹配链为 `scryfall_card.oracle_id → oracle_tagging.oracle_id → oracle_tag.tag_id`。
- 标签名称从 `oracle_tag.label` 匹配；后续如要完整支持 Scryfall slug，应在数据模型中保留 `slug`，不能仅靠不可逆字符串猜测。
- 多个空格分隔条件默认使用 AND 组合；OR、括号、否定及其他 Scryfall 风格语法应按明确的分期支持列表实现，未支持的操作符必须报错。

## 4. 标签点击跳转

- 卡牌详情的“功能标签”页签按钮只切换内容，不触发查询或页面跳转。
- 页签切换后，点击内容区中的某一个具体功能标签才生成 `otag:<标签>` 查询，并进入本页面。
- 标签含空格或特殊字符时使用双引号包裹并正确转义。
- 标签跳转与用户手工输入相同语法必须得到相同查询结果、路由和面包屑。

## 5. 面包屑

搜索结果页的面包屑固定为：

```text
全部卡牌 > 对应搜索条件的语法
```

- “全部卡牌”返回 Set 列表页。
- 第二段显示本次实际执行的规范化查询，例如 `otag:ramp`。
- 面包屑只显示查询，不额外插入“搜索结果”等中间层级。
- 查询过长时单行截断并提供完整查询提示；复制链接和路由中仍保存完整查询。

## 6. 结果列表

- 结果区复用 Set 卡牌列表的纯卡图网格，不在卡图下增加说明框。
- 右侧显示完整查询结果总数，不显示当前已加载数量。
- 使用无限滚动，不显示分页按钮。
- 查询或排序变化时清空已加载结果并重置游标。
- 全局搜索是否按 `oracle_id` 去重展示一张代表印刷，或展示所有具体印刷版本，尚未确认；实现前必须确定，不能由客户端随机选择。

## 7. 排序

- 语法搜索结果跨越多个 Set，不提供收藏编号排序；收藏编号排序只属于指定 Set 的卡牌列表。
- 可选排序项至少包括：
  - 发行日期：从新到旧、从旧到新；默认使用从新到旧。
  - 卡牌名称：A 到 Z、Z 到 A。
  - 法术力值：从低到高、从高到低。
- 页面首次进入、提交新查询或清除排序参数时，都恢复“发行日期从新到旧”。
- 发行日期相同时，依次使用 Set 代码、收藏编号原值和卡牌稳定唯一标识作为平局键，保证滚动分页顺序稳定。
- 搜索结果继续使用服务端游标分页；默认新到旧排序按 `released_at` 降序读取，不能一次性把跨 Set 的完整搜索结果发送给浏览器。

## 8. 后续语法范围

- 搜索语法参考 Scryfall 的表达方式，但只实现本地数据模型能够可靠支持的字段。
- 第一阶段至少支持普通卡名和 `otag:`；颜色、类别、法术力值、稀有度、Set、语言、收藏编号及布尔组合应逐项确认后加入。
- 页面需要提供可发现的语法帮助入口，列出本系统实际支持的操作符，不能宣称完全兼容 Scryfall。
