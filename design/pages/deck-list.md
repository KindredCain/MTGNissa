# 卡组列表页面设计规则

## 1. 页面定位

- 页面名称：卡组。
- 对应原型：`Screen / Deck List`。
- 入口路径：一级菜单“卡组”。卡组没有二级菜单，但保留与“我的卡牌”二级标头相同视觉规格的页面身份栏；该栏只承载标题、说明和页面操作，不表示新增菜单层级。
- 页面用于创建、查看和管理当前实例中的卡组；不展示社区作者、浏览量、公开标签、价格或赛制合法性。
- 页面整体框架沿用本系统其他桌面列表页。Archidekt Deck Search 只作为卡组信息卡片的布局参考，不复制其导航、广告、社区搜索或深色主题。

## 2. 页面结构

1. 全站一级导航，当前选中“卡组”。
2. 100 px 高的深绿色渐变页面身份栏，视觉风格与“我的卡牌”标头一致；左侧为标题“卡组”和说明“管理、查看和继续编辑我的卡组”，右侧为橙色“新建卡组”操作，不显示二级切换按钮。
3. 单行吸顶搜索和排序工具栏；滚动卡组卡片时固定在一级导航下方。
4. 卡组信息卡片网格。

“新建卡组”创建空白卡组，成功后进入该卡组的文本编辑页。卡组身份栏仅复用“我的卡牌”的背景、标题、说明和间距风格，不增加与一级菜单重复的二级切换按钮。

## 3. 搜索、筛选与排序

- 名称搜索框文案为“按卡组名称搜索”，只作为卡组 list 接口的名称关键字参数，不解析卡牌搜索语法。
- 卡组列表不提供状态筛选。
- 排序选项为“最近更新”“创建时间”“名称”“卡牌总数”。每个选项使用产品定义的固定方向：最近更新和创建时间从新到旧，名称按自然正序，卡牌总数从多到少。
- 页面不显示独立的升序、降序按钮或方向标识。
- 右侧显示当前条件下的结果总数，例如“共 12 个卡组”。
- 不再额外显示与状态下拉重复的“全部 / 无异常 / 有异常”快捷筛选，也不在当前原型提供网格/列表视图切换。

单用户数据量允许名称条件使用普通 `LIKE` 查询；现阶段不因此新增卡组名称索引。若真实规模证明需要索引，再单独调整 App DB 结构。

## 4. 卡组信息卡片

卡片参考 Archidekt Deck Search 的信息顺序，但只使用本系统已有或可派生的数据：

1. 顶部为单张横向裁切的卡牌封面，不使用多张卡图拼接。桌面端卡片尺寸固定为 328 × 292 px，封面视口固定为 328 × 180 px；标准卡图等比显示为 328 × 457 px，并相对封面顶部固定偏移 `-54 px`。上述尺寸和取景位置作为本页实现基准，不再按不同卡牌单独调整；不得把卡牌最上沿或下半部规则文字作为封面主体。
2. 最近更新时间参考 Archidekt 的轻量相对时间样式，固定在封面右下角，距右侧 12 px、距底部 8 px；只显示小型时钟图标和“12 分钟前”“昨天”等相对时间文字，不使用胶囊、底框或色块，也不随渐变区域或卡图取景位置移动。封面不显示总牌数或异常信息。
3. 封面下方显示六色含量比例带。
4. 信息区显示卡组名称；分区数量摘要同一行的右侧显示“共 X 张”；底部使用固定高度的左右布局，异常类型固定在左下角，“查看卡组”固定在右下角，二者不得因文案长度互相挤压或改变垂直位置。
5. 卡片右侧的更多操作菜单包含编辑、重命名、复制和删除。

点击卡片非操作区域或“查看卡组”按 `deck_id` 进入对应卡组详情页。更多操作按钮必须阻止卡片跳转，不能按名称定位卡组，因为名称不要求唯一。

卡图来自外部 CDN 地址时仍使用同一裁切方式：前端直接显示原始卡图 URL，通过固定封面容器、等比覆盖和可配置的纵向取景位置完成视觉裁切，不需要下载或生成一张新的封面图。普通图片展示不依赖读取图片像素；实现时需在站点 CSP 的 `img-src` 中允许卡图 CDN，并提供加载失败占位。若以后需要将外链图片绘制到 Canvas 或导出像素，才需要额外确认图片源的 CORS 响应头。

封面底部参考 Archidekt 卡组卡片的柔和衔接方式，从封面内 `y = 108 px` 开始叠加 72 px 高、由透明到纯白的纵向渐变，使卡图逐步淡出后进入六色比例带和信息区；不得使用一条不透明横框直接切断卡图。渐变末端至少 8% 的高度保持纯白，六色比例带容器也必须显式使用同一纯白底色。此前出现的细缝并非坐标间隙，而是渐变终点与下一层透明背景在裁切边缘发生插值造成；固定纯白末段和后继背景后消除该缝隙。

### 4.1 封面选择

- 卡组存在指挥官时，使用指挥官区按稳定顺序取得的第一张逻辑卡作为封面。
- 没有指挥官时，使用主牌区按卡名和 `oracle_id` 稳定排序后的第一张逻辑卡。
- 具体印刷版本继续使用既有“收藏版本 → 愿望单版本 → 其他最新印刷版本”自动选择规则。
- 空卡组显示统一的无卡图占位，不尝试使用外部随机图片。

### 4.2 六色含量比例带

- 比例带固定只使用白、蓝、黑、红、绿、无色六种产品颜色，顺序不可变化，不得使用随机颜色或由卡图取色。
- 数据来自指挥官、主牌和备牌中逻辑卡牌的卡牌颜色；备选区不参与。每条记录按编辑数量计权，多色牌的数量分别计入其包含的每一种颜色，颜色集合为空的牌计入无色。
- 每一段宽度为该颜色计权数量占六类计权总量的比例；数量为零的颜色段不显示。比例只表达卡组颜色含量，不表达颜色标识、产费结构或赛制合法性。
- 六类计权总量为零时只显示完整的无色段。

### 4.3 数量与异常

- 卡组总牌数只统计指挥官、主牌和备牌；备选区不计入总数。
- 分区摘要按实际存在的分区显示，例如“指挥官 1 · 主牌 99 · 备选 8”或“主牌 60 · 备牌 15”；同一行右侧显示“共 X 张”。
- 卡组列表信息卡片左下角保留异常状态提示，只显示“数量不足”或“多卡组占用”，不显示异常项数量；无异常时不渲染状态提示。
- 卡组列表不提供异常状态筛选。
- 页面不得显示“合法 / 非法”，因为当前不进行卡组合法性校验。

## 5. 卡组操作

- 编辑：进入该卡组文本编辑页。
- 重命名：就地弹出轻量输入对话框；成功后前端即时更新卡名。
- 复制：创建新的 `deck_id` 和卡组明细，名称使用明确的副本名称，然后保持在列表中并展示新卡片。
- 删除：二次确认后删除卡组；成功后从当前列表移除。
- 所有变更均按现有规则写入操作日志。失败时保留原状态并显示轻量错误提示。

## 6. 页面状态

- 首次加载显示与卡片尺寸一致的骨架占位。
- 查询无结果显示“没有符合条件的卡组”，并提供清除筛选入口。
- 尚未创建任何卡组时显示“还没有卡组”，主操作为“新建卡组”。
- 封面加载失败时保留封面高度并显示统一占位，不影响卡组名称、数量和操作。
- 列表请求失败时保留标题和工具栏，显示重试入口。
