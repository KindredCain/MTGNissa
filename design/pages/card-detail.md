# 可复用卡牌详情

## 1. 页面定位

- 页面名称：卡牌详情。
- 对应原型：`Screen / Card Detail`、`Screen / Card Detail — Official Rulings`、`Screen / Card Detail — Function Tags`。
- 本页面可以从全部卡牌、我的卡牌、愿望单和卡组等位置复用，不绑定某个卡牌中心二级页面。
- 页面保留全站一级导航，不显示“全部卡牌 / 我的卡牌 / 愿望单”二级标头。
- 当前页面上下文由具体印刷版本及实体语言确定；逻辑卡牌汇总使用 `oracle_id`。

## 2. 页面结构

页面依次包含：

1. 全站一级导航。
2. 系列、语言和卡牌名称面包屑。
3. 卡牌主体：当前语言卡图、固定中文说明、收藏操作与汇总。
4. 当前系列的其他可用语言。
5. 同一逻辑卡牌的其他系列版本及其可用语言。
6. 卡组使用情况。

## 3. 面包屑与返回路径

面包屑格式固定为：

```text
Set 名称（语言） > 卡牌名
```

- Set 名称优先使用中文名称，没有中文名称时回退英文名称。
- 实体语言使用中文语言名并放在 Set 名称后的全角括号内，不使用独立语言标签。
- 点击 `Set 名称（语言）` 返回该 Set、该语言的卡牌列表页；不得按默认语言重新选择。
- 卡牌名显示当前页面采用的中文展示名；没有中文名时回退英文名。

## 4. 卡图与固定中文说明

### 4.1 左侧卡图

- 左侧显示当前具体印刷版本、当前实体语言对应的完整卡图。
- 卡图来源按数据字典规定，由 `scryfall_id`、`face_index` 和 `layout` 生成；不得用中文说明语言代替实体卡语言。
- 使用适合详情阅读的完整大图规格并保持原始宽高比，不裁切卡面。
- 多面牌按统一牌面规则提供正反面查看；图片加载失败时显示统一卡背或缺图占位。

### 4.2 中间说明

- 中间区域固定显示中文卡牌说明，不跟随当前实体卡语言变化。
- 中文内容由 `face_oracle_id` / `oracle_id` 关联中文名称、类别、规则文本和释疑；单项中文缺失时按系统已有规则回退英文原文。
- 保留现有名称、法术力费用、系列、收藏编号、稀有度、规则文本和释疑布局。
- 删除原有“实体语言”元数据块及语言回退说明，实体语言只在面包屑、卡图和语言选项中表达。

### 4.3 官方释疑

- “官方释疑”页签按钮只切换内容，不离开详情页。
- 内容按 `scryfall_card.oracle_id → scryfall_oracle_ruling.oracle_id → zhs_ruling.ruling_key` 取得。
- 每条释疑显示发布日期和来源；`source = wotc` 在界面显示为 `WotC`。
- 正文优先显示 `zhs_ruling.translation`；中文缺失时显示 `zhs_ruling.comment` 英文原文。
- 中文回退属于内部展示规则，标题区只显示释疑数量，不展示“中文优先”等说明文案。
- 样例同时以较弱层级保留英文原文，用来表达中英文对应关系；正式实现可以根据最终信息密度决定默认显示或折叠英文。
- 默认按发布日期从新到旧排列；日期相同按源记录稳定标识排序。
- 当前原型使用“生机妮莎”的 3 条真实本地释疑样例。

### 4.4 功能标签跳转

- “功能标签”页签按钮只负责切换到标签内容区，本身不是搜索链接，点击时不得跳转到搜索结果页。
- 切换到“功能标签”后，内容区显示的每一个具体标签才是独立搜索入口，不只用于静态展示。
- 点击标签后构造规范查询 `otag:<标签>` 并进入“全部卡牌”的语法搜索结果页；标签包含空格或特殊字符时使用双引号，例如 `otag:"mana rock"`。
- 标签查询使用当前卡牌的 `oracle_tagging.tag_id` 关联 `oracle_tag`；界面展示 `oracle_tag.label`，搜索结果仍按 `oracle_id` 匹配标签关系。
- 当前数据模型未保存 Scryfall Tagger 的 `slug`，因此页面生成查询时使用可逆的带引号 `label`；若后续要求完全兼容 Scryfall slug，再将 `slug` 纳入卡牌数据模型。
- 标签跳转和右上角搜索框必须进入同一个查询解析及结果页面，不能实现两套不同语义。
- 标签内容区使用当前卡牌的真实标签样例；标签卡片显示 `oracle_tag.label` 及将要执行的 `otag:` 查询，并提供明确的跳转箭头。

## 5. 我的收藏与数量口径

右上“我的收藏”保留普通卡、闪卡数量调整和愿望单操作，同时明确区分以下数量：

- “我的收藏”标题是导航入口，点击后进入 `卡牌中心 → 我的卡牌`列表页；该入口进入完整的我的卡牌列表，不因当前详情页来源改变目标页面。

- 当前版本拥有：当前 `scryfall_id` 对应具体印刷及语言版本的普通卡与闪卡数量。
- 该卡收藏数量：按 `oracle_id` 汇总该卡所有系列、收藏编号和实体语言的普通卡与闪卡数量，并显示合计。界面不得使用“逻辑卡收藏数量”等技术名称。
- 其他系列版本拥有：在某一其他系列版本行内，汇总该版本所有可用语言的拥有数量。
- “该卡收藏数量”包含普通画框、全图、异画、展示框及其他共享同一 `oracle_id` 的印刷版本；`scryfall_card.full_art` 只用于标识全图版本，不作为收藏汇总过滤条件。

没有 `oracle_id` 的对象按数据模型约定使用 `scryfall_id` 作为独立逻辑分组，不能把所有空 `oracle_id` 记录合并。

## 6. 当前系列语言

- 收藏卡片下方显示“当前系列语言”。
- 使用单个下拉选择框，不使用横排语言按钮；右栏宽度有限，按钮方案在语言数量较多时会换行并造成区域臃肿。
- 选择框默认显示当前实体语言，并附带可选语言数量；展开后列出当前 Set、收藏编号对应的全部可用实体语言。
- 下拉列表只显示实际存在卡牌记录的语言，不显示不可用语言，也不使用置灰占位。
- 选择语言后进入同一 Set、同一收藏编号、所选实体语言对应的卡牌详情。
- 下拉选项由当前印刷分组内 `scryfall_card.lang` 去重得到，语言名称来自 `scryfall_language`。

## 7. 其他系列版本

- 只展示与当前卡具有相同 `oracle_id` 的其他系列版本。
- 页面按系列版本合并展示，不为每种语言重复一行。
- 整个“其他系列版本”区域使用固定高度，不随版本数量继续撑高详情页。
- 标题右侧显示版本总数；版本列表放在内部滚动区，超出可视高度的内容隐藏，并始终保留可见的纵向滚动条。
- 版本行使用紧凑布局：缩小上下内边距、行间距和语言标签高度，但系列名称、拥有数量及语言入口仍必须清晰可点。
- 每个版本标题显示 `Set 名称 · Set 缩写`；标题后显示该版本全语言汇总的拥有数量。
- 每个版本下方列出该版本实际存在的全部可用语言。
- 不可用语言完全不显示，不使用 Set 列表中的置灰表达。
- 点击具体语言进入该系列版本、该语言对应的卡牌详情；语言跳转语义与 Set 列表的语言按钮一致，始终精确保留目标语言。
- 当前版本不在“其他系列版本”中重复出现。
- 版本排序默认按发布日期从新到旧；发布日期相同时按 Set 缩写、收藏编号和稳定唯一标识排序。
- 滚动仅作用于版本列表，标题、版本总数和详情页其他区域保持不动。

### 7.1 合并键

- 逻辑卡范围：`oracle_id`。
- 系列版本范围：`set_id + collector_number`，语言不参与版本分组。
- 具体可跳转实体：该版本分组中的 `scryfall_id + lang`。
- 若同一逻辑卡在同一 Set 中存在多个收藏编号，必须作为不同版本展示，不能仅按 `set_id` 合并。

## 8. 卡组使用情况

- “卡组使用情况”保持现有设计并放在右栏最后。
- 卡组使用按逻辑卡牌 `oracle_id` 汇总，不受当前印刷版本或实体语言影响。
- 数量与卡组数沿用应用数据模型中对主牌、备牌和指挥官区的统计规则；备选区不计入占用判断。
- 每个具体卡组名称都是可点击入口，并应提供明确的链接视觉提示。
- 点击卡组名称后按该行的 `deck_id` 进入对应卡组详情页；不能只进入卡组列表，也不能按卡组名称查询，因为名称不保证唯一。
- 行尾数量仅表示该卡在该卡组中的使用数量，不作为独立跳转目标。

## 9. 页面状态与异常处理

- 页面应区分首次加载、收藏更新中、收藏更新失败、卡图失败和详情加载失败。
- 切换语言或系列版本后，面包屑、卡图和当前版本收藏数量必须同步更新；固定中文说明及“该卡收藏数量”继续对应同一 `oracle_id`。
- 某版本没有任何可用语言时不渲染该版本。
- 语言或版本跳转目标失效时返回可恢复错误，不得静默跳到其他语言。

## 10. 当前未确认事项

- 多面牌在详情页使用翻面控件、双图并排还是其他交互形式，需在统一卡图交互设计时确认。
- 其他系列版本一次性全部展示还是在数量过多时折叠，尚未确定。
