## 文档约定

- 功能范围与验收以[需求基线](../docs/requirements.md)为准，Card DB 字段及链路见[新数据字典](../docs/card-data-dictionary.md)，个人数据身份及快照见[App DB 目标设计](../docs/app-data-schema.md)。原型图和页面说明负责界面结构、展示内容与交互反馈；接口方法、路径、参数、响应 DTO、错误码、分页方式以及由服务端保证的结果顺序统一以 [API 契约](../docs/api-contract.md)为准。原型中的样例数据不得被解释为另一套接口规则，前端也不得在页面说明未明确要求时自行改写后端返回结构或顺序。

### 语言口径

- 普通卡牌具体语言印刷版本的业务标识统一为 `mtgnissa_card_printing.uuid`，本文档及页面说明记为 `printing_uuid`；双面或多牌面牌使用主牌面的语言印刷 UUID 作为版本入口，其余牌面随同返回，不拆分收藏。详情、收藏、愿望单、卡组候选、封面引用及日志使用该标识；`scryfall_id` 仅用于图片及已有非语言查询中的外部元数据，不替代业务身份。具体 API 字段与路径以 [API 契约](../docs/api-contract.md) 为准。
- 规则和数据内部区分“卡牌原语言”与“翻译后语言”。卡牌原语言来自 `mtgnissa_card_printing.language_code`，具体印刷语言业务统一通过 `mtgnissa_card_printing -> mtgnissa_card -> 翻译` 读取；翻译后语言决定卡牌名称、类别、规则文字、风味文字和官方释疑等说明内容，当前为简体中文，缺失时回退对应英文内容。不需要区分具体印刷语言的全局搜索、卡组代码解析、逻辑卡聚合与统计以及 Oracle 级查询可直接使用 `mtgnissa_card -> 翻译或 Oracle 数据`。
- Set 列表、卡牌详情和操作日志中涉及卡牌原语言的可见名称统一使用 `scryfall_language.display_name`；前端原样消费该内置展示名，不维护语言代码到名称的固定映射。
- UI 不暴露“原语言”或“翻译后语言”术语。所有筛选、按钮、下拉框、面包屑和合并选项统一显示“语言”，其交互语义均为卡牌原语言。
- 翻译后语言不提供 UI 筛选或切换，只在展示卡牌信息时生效；卡牌说明不跟随 UI 中的“语言”切换。
- 普通 Set 列表行中点击具体可用语言直接进入对应语言的卡牌列表；点击整条普通 Set 横条的其他区域进入该行从左到右第一个可用语言，不使用隐藏的简中或英文优先级。Token Set 不显示语言按钮，点击行直接进入无语言参数的完整 Token 列表；该列表只展示总数与卡图，不提供搜索、筛选、排序或普通卡牌详情入口。
- 普通卡牌仅在解析卡图时，允许语言印刷行缺少 `scryfall_id` 后使用关联的 `mtgnissa_card.scryfall_id` 获取基础卡图；图片由后端解析并返回。该回退只改变图片来源，不改变印刷版本身份、语言、详情目标、收藏、愿望单、卡组或日志，也不能用图片 ID 替换业务标识。Token 独立处理，缺少图片 ID 时显示缺图占位。

### 列表快捷操作边界

- 全部卡牌列表只浏览，不提供拥有数量或愿望单快捷操作；具体 Set 卡牌列表和语法搜索结果列表均遵循此规则。
- 我的卡牌列表只提供普通卡、闪卡拥有数量的快速加减，不提供愿望单快捷操作。
- 愿望单列表只提供愿望单状态的快速取消与恢复，不提供拥有数量编辑。
- 卡牌详情页是独立的可复用页面，其收藏与愿望单操作不受列表快捷操作边界限制。
- 收藏数量和愿望单快捷操作统一等待后端成功后才更新显示；请求期间锁定当前卡位或详情收藏面板的全部相关操作，禁止连续点击。失败时原状态不变并打开统一错误弹窗。
- 所有能够取得不同正反面卡图的双面或多牌面印刷均按一个结果、一个标准卡位展示；默认正面，使用卡牌插画区域右上角的翻面按钮在原位切换背面，按钮不得遮挡牌名栏或法术力费用标志。`split`、`flip`、`adventure` 等多个规则牌面共用同一张正面卡图的单面布局不显示翻面按钮。我的卡牌共享一组数量操作，愿望单共享一个星标状态。
- 上述双面或多牌面印刷的详情页使用卡图下方的独立“查看反面／查看正面”按钮，不使用列表页的图上叠加按钮；翻面时卡图、中间对应牌面的中文说明和名称右上角的法术力费用符号同步切换，费用直接读取当前 `faces[]` 项的 `mana_cost`，不重新请求详情，右侧印刷版本与个人数据保持不变。卡牌摘要与卡组统计的 `cmc`、`mana_cost`、`colors`、`produced_mana` 固定取主牌面，`is_land` 则在任一牌面属于地时为真。

### 搜索入口边界

- 右上角全局搜索框支持普通卡名和首版查询语法，提交后进入独立搜索结果页；功能标签也进入同一语法查询流程。首版语法范围以功能需求第 2.2 节及其引入的[搜索语法支持矩阵](../docs/search-syntax-support.md)为共同基线，矩阵当前保留的名称、颜色与颜色标识、卡牌类别、关键字异能、法术力值、力量/防御力/忠诚值、多面牌、牌类派生、稀有度、系列、Oracle 功能标签、`OR` 和嵌套条件均必须支持；Card Text 只支持 `keyword:`、`kw:`，Mana Costs 只支持 `mv:`、`manavalue:`，Tagger Tags 只支持 `otag:`、`oracletag:`、`function:`。能够被解析器完整识别的输入执行语法查询，其他输入统一按完整原文执行卡名模糊查询，不显示语法错误。搜索框右侧的“？”按钮在新标签页打开 Scryfall 官方语法说明，该外链不扩展本系统的首版支持范围。
- 提供内容区搜索框的列表只做名称关键字搜索，不解析查询语法。Set 索引匹配顶层系列名称或代码；普通 Set 卡牌列表匹配 `mtgnissa_card_printing.printed_name`，收藏及愿望单匹配关联基础卡面的英文名称。Token 没有内容区搜索框。
- 普通列表关键字变化并提交后重新请求对应 list 接口、重置列表位置；普通 Set 的筛选和排序复用一次取得的完整轻量结果。
- 卡组增加卡牌是独立入口：按钮或联想点击才执行 `printed_name LIKE '%q%'` 正式搜索，按钮无最小长度或字符类型限制，空关键字不加名称条件；输入至少包含 3 个英文字母或 2 个汉字时，才防抖执行 `q%` 联想，最多 5 个去重名称。点击联想回填全名并立即正式搜索，输入变化和联想响应均不刷新正式结果；忽略过期响应。详情规则见 [deck-edit.md](pages/deck-edit.md)。

### 层级与加载口径

- Set 索引按 `parent_code` 形成父组，只对顶层父节点查询、筛选、排序及游标分页；完整子树始终随父节点缩进，同父节点普通子 Set 在前、Token Set 在后，各组按发行日期升序、代码升序递归展开。总数按父组计，分页不拆子树。
- 普通及 Token Set 卡牌一次取得完整轻量结果，前端本地分批渲染图片；全局搜索、收藏、愿望单、卡组列表及正式增牌结果按服务端游标加载；操作日志固定每页 10 条。联想最多 5 个名称，不分页。
- Set 索引 `card_count` 保留导入卡面数，卡图列表的总数是组织多牌面后的印刷项数，两者允许不同。
- 卡牌操作日志保存主牌面版本 UUID、文字、语言及 `images` 快照；历史读取不补查当前 Card DB 改写快照，日志明细行保持只读。

### 多选筛选下拉框

- 卡牌中心各列表页的多选筛选统一复用 `.pen` 中的 `Prototype / Multi-select Filter Dropdown — Open`。打开期间勾选只修改临时选择；点击下拉框外部立即关闭，选择变化时在关闭完成后仅执行一次查询或本地筛选，未变化时不触发。下拉框不提供“确定”或“取消”按钮。

### 空列表与反馈

- 查询结果为 0 时列表内容区直接为空，不设计专用空状态。请求、校验、解析、剪贴板及后端意外错误统一复用无右上角关闭叉、固定 520 px 宽且高度随正文增长的错误弹窗；后端安全错误信息直接作为普通正文展示，不加标题或外框。
- 复制卡组代码成功使用不可交互、约 2.5 秒自动消失的非阻断提示，原页面继续保持可操作。
- 卡组列表与卡组详情的“删除卡组”共用 `Prototype / Delete Deck Confirmation Modal`。删除入口使用危险色，必须先确认；确认弹窗不设置右上角关闭按钮且点击遮罩不关闭，只能通过“取消”或“删除卡组”完成选择。

### 全局桌面视口与滚动基线

- `1440 × 900` 是桌面浏览器视口与首屏校验基线。部分 Full Page 原型会使用更高画板把完整长页面内容摊开展示，该画板高度只服务设计评审，不代表实际浏览器高度，也不得直接转换为实现中的固定页面高度。
- 实际实现中，一级导航、卡牌中心二级标头以及各页面已确认的吸顶区域保留在浏览器视口上方，超出首屏的正文由页面滚动承载。
- 所有遮罩、居中弹窗和明确要求视口固定的书签均相对“当前浏览器视口”定位，而不是相对长页面画板或打开时的文档坐标定位。背景页面发生滚动时，固定弹层仍保持在当前视口位置。
- 模态弹窗或模态抽屉打开期间必须锁定底层页面滚动并阻止全部底层交互。滚轮、触控滑动和键盘滚动不得穿透遮罩；存在超出内容时，只滚动弹窗内部明确指定的内容区域，或卡组统计抽屉所属的统计遮罩页，绝不滚动底层页面。关闭后恢复底层页面打开前的滚动位置。
- “增加卡牌”和“操作日志详情”悬浮窗使用不带背景模糊的阻断遮罩，点击遮罩或底层页面不关闭，只能点击悬浮窗右上角关闭按钮。卡组编辑的离开确认弹窗同样使用不带背景模糊的阻断遮罩，但不设置右上角关闭按钮，只能通过“继续编辑”或“放弃修改并离开”完成选择。卡组统计抽屉使用模糊背景，允许点击未被抽屉覆盖的模糊区或再次点击书签关闭；这些关闭逻辑不得混用。
- 页面主体默认保留左右各 40 px 的安全留白，对应 1360 px 内容区。
- 设计文件只保留 1440 × 900 主原型，不为 1366 × 768、1280 × 720 等常用桌面尺寸复制整页画板。1280 px 及以上视口通过流式容器、Flex/Grid 重排、媒体查询或容器查询适配可用空间，不使用整页 `transform: scale()` 或等效等比缩放。页面主体固定最小布局宽度 1280 px；视口低于 1280 px 时停止继续重排或降列，由浏览器提供整页横向滚动查看完整布局。
- 卡图列表在 1440 px 视口使用五列，1366 px 与 1280 px 宽度自动降为四列。卡图保持 244 × 340 px、横向间隔保持 35 px，剩余空间留在行尾；不得缩放字体、按钮、点击热区或卡图来硬塞更多列。
- 卡组详情和编辑的八种类型列在 1440 px 完整显示；1280 px 及以上视口中，可用宽度不足时保持列宽与列坐标，通过当前主牌、备牌或备选区域内部横向滚动查看，不换行、不压缩卡图。低于 1280 px 时页面同时遵循全局最小宽度规则，由浏览器提供整页横向滚动。
- 常用桌面尺寸仍需在实现和验收时覆盖 1280、1366、1440 与更宽视口，但不要求在 `.pen` 中永久维护对应的重复画板。视口高度低于 720 px 时使用浏览器正常纵向页面滚动，不缩放页面。940 × 702 px 的增加卡牌悬浮窗和 1040 × 650 px 的日志明细悬浮窗属于例外：打开时仍锁定底层页面，空间不足时使用 `max-width`、`max-height` 和悬浮窗内部滚动；卡组统计抽屉继续滚动其统计遮罩页，均不依赖底层浏览器滚动，也不缩放整个悬浮窗内容。

每个页面文档至少记录：

1. 页面定位和入口。
2. 导航及页面层级。
3. 数据来源和派生规则。
4. 查询、筛选、排序和加载规则。
5. 页面状态及异常回退。
6. 已确认规则和待确认事项。

设计评审中确认的新规则，应同步更新对应页面文档，不能只保留在原型或对话中。
