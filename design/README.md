## 文档约定

### 全局桌面视口与滚动基线

- 所有正式页面原型统一使用 `1440 × 900` 桌面浏览器视口；长页面不得通过增加画板高度表达完整内容。
- 一级导航、卡牌中心二级标头以及各页面已确认的吸顶区域保留在视口上方，超出首屏的正文在页面内部纵向滚动。
- 页面主体默认保留左右各 40 px 的安全留白，对应 1360 px 内容区。
- 卡图列表在 1440 px 视口使用五列；更窄的桌面视口通过减少列数适配，不横向压缩或裁切卡图。

每个页面文档至少记录：

1. 页面定位和入口。
2. 导航及页面层级。
3. 数据来源和派生规则。
4. 查询、筛选、排序和加载规则。
5. 页面状态及异常回退。
6. 已确认规则和待确认事项。

设计评审中确认的新规则，应同步更新对应页面文档，不能只保留在原型或对话中。
