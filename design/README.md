# MTG Nissa 设计说明

本目录保存产品原型、原型使用的静态资源，以及页面设计过程中确认的逻辑规则。

## 目录结构

- `mtgnissa.pen`：pen.dev 原型文件。
- `assets/`：原型使用的本地静态资源。
- `pages/`：页面级设计规则，每个页面使用独立文档。

## 文档约定

每个页面文档至少记录：

1. 页面定位和入口。
2. 导航及页面层级。
3. 数据来源和派生规则。
4. 查询、筛选、排序和加载规则。
5. 页面状态及异常回退。
6. 已确认规则和待确认事项。

设计评审中确认的新规则，应同步更新对应页面文档，不能只保留在原型或对话中。
