## 文档约定

### 语言口径

- 规则和数据内部区分“卡牌原语言”与“翻译后语言”。卡牌原语言来自 `scryfall_card.lang`，决定具体印刷记录及卡图；翻译后语言决定卡牌名称、类别、规则文字、风味文字和官方释疑等说明内容，当前为简体中文，缺失时回退对应英文内容。
- UI 不暴露“原语言”或“翻译后语言”术语。所有筛选、按钮、下拉框、面包屑和合并选项统一显示“语言”，其交互语义均为卡牌原语言。
- 翻译后语言不提供 UI 筛选或切换，只在展示卡牌信息时生效；卡牌说明不跟随 UI 中的“语言”切换。
- Set 列表中点击具体可用语言直接进入对应语言的卡牌列表；点击整条 Set 横条的其他区域进入该行从左到右第一个可用语言，不使用隐藏的简中或英文优先级。

### 列表快捷操作边界

- 全部卡牌列表只浏览，不提供拥有数量或愿望单快捷操作；具体 Set 卡牌列表和语法搜索结果列表均遵循此规则。
- 我的卡牌列表只提供普通卡、闪卡拥有数量的快速加减，不提供愿望单快捷操作。
- 愿望单列表只提供愿望单状态的快速取消与恢复，不提供拥有数量编辑。
- 卡牌详情页是独立的可复用页面，其收藏与愿望单操作不受列表快捷操作边界限制。
- 所有卡图列表中的模式双面牌均按一个结果、一个标准卡位展示；默认正面，使用卡牌插画区域右上角的翻面按钮在原位切换背面，按钮不得遮挡牌名栏或法术力费用标志。我的卡牌共享一组数量操作，愿望单共享一个星标状态。
- 模式双面牌详情页使用卡图下方的独立“查看反面／查看正面”按钮，不使用列表页的图上叠加按钮；翻面时卡图和中间对应牌面的中文说明同步切换，右侧印刷版本与个人数据保持不变。

### 搜索入口边界

- 右上角全局搜索框支持普通卡名和查询语法，提交后进入独立搜索结果页；功能标签也进入同一语法查询流程。
- 各列表页内容区中间的搜索框只做名称关键字搜索，并把关键字传给当前页面的 list 返回接口；它不解析任何查询语法。
- 卡牌列表使用卡名关键字，Set 列表使用系列名称或缩写关键字。列表关键字变化时重新请求对应 list 接口并重置列表位置。

### 全局桌面视口与滚动基线

- 所有正式页面原型统一使用 `1440 × 900` 桌面浏览器视口；长页面不得通过增加画板高度表达完整内容。
- 一级导航、卡牌中心二级标头以及各页面已确认的吸顶区域保留在视口上方，超出首屏的正文在页面内部纵向滚动。
- 页面主体默认保留左右各 40 px 的安全留白，对应 1360 px 内容区。
- 卡图列表在 1440 px 视口使用五列；更窄的桌面视口通过减少列数适配，不横向压缩或裁切卡图。

每个页面文档至少记录：

1. 页面定位和入口。
2. 导航及页面层级。
3. 数据来源和派生规则。
4. 查询、筛选、排序和加载规则。
5. 页面状态及异常回退。
6. 已确认规则和待确认事项。

设计评审中确认的新规则，应同步更新对应页面文档，不能只保留在原型或对话中。
