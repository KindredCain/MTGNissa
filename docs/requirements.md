# MTGNissa 功能需求

## 文档状态

- 状态：需求草案
- 范围：卡牌查看、个人卡牌、愿望单、卡组和操作日志
- 暂不包含：数据库表、API、完整查询条件和页面具体布局

## 1. 功能范围

系统包含：

```text
卡牌中心
├── 全部卡牌
├── 我的卡牌
├── 愿望单
└── 卡牌详情

卡组
├── 卡组列表
├── 卡组编辑
├── 卡组展示
└── 卡组统计

操作日志
├── 每日操作汇总
└── 操作明细
```

全部卡牌、我的卡牌和愿望单应复用卡牌列表、详情及管理操作，不建立三套重复页面。

## 2. 卡牌查看与检索

已确认需要：

- 查看 Set 列表
- 选择 Set 查看该 Set 的卡牌
- 根据卡名搜索
- 根据费用搜索
- 从检索结果进入卡牌详情
- 从列表修改拥有数量
- 从列表管理愿望单

完整查询能力暂不确定，后续根据参考网站交互、卡牌数据库模型、数据库实际字段以及索引和查询能力设计。

不要求实现完整 Scryfall 搜索语法。

## 3. 卡牌详情

卡牌详情以具体印刷版本为入口：

```text
Set + 收藏编号
```

展示内容包括：

- 卡图
- 双面牌或多牌面的所有内容
- 卡名
- 费用
- 类型
- 卡牌文字
- 力量、防御、忠诚等属性
- Set
- 收藏编号
- 稀有度
- 印刷版本语言
- 数据库提供的其他必要字段

### 3.1 说明语言

卡牌详情不提供说明语言切换。

卡牌名称、类型、规则文字等说明内容：

```text
优先使用配置文件指定语言
    ↓
不存在时显示英文
```

说明语言与实体卡语言相互独立。

例如拥有日文实体卡、系统配置为简体中文时：

```text
版本语言：日文
说明文字：简体中文
```

简体中文说明不存在时显示英文。

### 3.2 印刷版本

详情页展示同一逻辑卡牌的全部印刷版本：

- 不同 Set
- 不同收藏编号
- 不同语言
- 各版本拥有数量
- 各版本愿望单状态

支持切换到其他印刷版本详情。

### 3.3 拥有数量

普通卡和闪卡在同一个数量字段中展示：

```text
普通卡数量:闪卡数量*
```

例如：

```text
3:1*
```

表示普通卡 3 张、闪卡 1 张。

详情页支持分别增加或减少普通卡和闪卡数量。

## 4. 我的卡牌

只展示拥有数量大于零的卡牌。

收藏数量至少区分：

```text
逻辑卡牌
+ Set
+ 收藏编号
+ 语言
+ 普通/闪卡
```

不为每一张实体卡建立独立档案。

### 4.1 排序

支持：

- 按 Set 和收藏编号排序
- 按颜色费用排序
- 按名称排序

颜色费用和收藏编号的具体排序规则，根据卡牌数据库模型确定。

### 4.2 Set 合并

按 Set 排序时不提供跨 Set 合并。

按颜色费用或名称排序时提供：

```text
[ ] 合并不同 Set
```

关闭时，不同印刷版本展示为多张卡：

```text
Lightning Bolt / M11 / 2:1*
Lightning Bolt / M10 / 3:0*
Lightning Bolt / 2X2 / 1:1*
```

这些卡牌按照排序结果连续展示。

开启时，同一逻辑卡牌展示为一张汇总卡：

```text
Lightning Bolt / 全部 Set / 6:2*
```

汇总卡可以查看各 Set 明细。

### 4.3 语言合并

收藏严格区分语言，并提供：

```text
[ ] 合并不同语言
```

关闭时：

```text
Lightning Bolt / M11 / 英文 / 2:1*
Lightning Bolt / M11 / 日文 / 1:0*
Lightning Bolt / M11 / 简中 / 3:0*
```

开启时：

```text
Lightning Bolt / M11 / 全部语言 / 6:1*
```

汇总卡可以查看语言明细。

### 4.4 合并组合

| Set 合并 | 语言合并 | 展示单位 |
| --- | --- | --- |
| 关闭 | 关闭 | 每个 Set、每种语言分别展示 |
| 开启 | 关闭 | 相同语言合并不同 Set |
| 关闭 | 开启 | 相同 Set 合并不同语言 |
| 开启 | 开启 | 每个逻辑卡牌展示一张 |

普通和闪卡始终通过 `普通:闪*` 汇总。

## 5. 愿望单

愿望单只展示用户明确标记的印刷版本。

愿望项严格区分：

```text
Set
+ 收藏编号
+ 语言
```

不跨 Set 合并，不跨语言合并。

愿望单不记录：

- 目标数量
- 闪卡偏好
- 备注
- 优先级

愿望项只支持：

- 加入愿望单
- 移出愿望单

不提供修改语言操作。需要改变语言时：

```text
移出原愿望项
    ↓
使用新语言重新加入
```

即使已经拥有该版本，也不自动移出愿望单。

可以从以下位置管理愿望单：

- 全部卡牌
- 我的卡牌
- 卡牌详情
- 愿望单

## 6. 卡牌中心复合

全部卡牌、我的卡牌和愿望单共享：

- 搜索与筛选
- 排序
- 卡牌列表或图片展示
- 卡牌详情入口
- 普通卡数量操作
- 闪卡数量操作
- 愿望单操作

页面可以通过范围切换实现：

```text
[全部卡牌] [我的卡牌] [愿望单]
```

具体使用标签页、独立路由或组合页面，在前端设计阶段确定。

## 7. 卡组列表

支持：

- 创建卡组
- 查看卡组
- 编辑卡组
- 修改卡组名称
- 复制卡组
- 删除卡组
- 查看更新时间
- 查看卡牌总数
- 查看异常卡牌数量
- 查看卡组统计

不进行卡组合法性校验。

## 8. 卡组编辑

使用简单文本编辑器编辑卡组。

基础格式：

```text
4 Lightning Bolt
2 Counterspell
1 Sol Ring
```

卡组记录：

```text
逻辑卡牌 + 编辑数量
```

不要求用户指定：

- Set
- 收藏编号
- 语言
- 普通或闪卡
- 展示版本

无法识别的行必须明确提示，不能静默丢弃。

是否支持主牌、副牌、指挥官和备选区等分区，后续确定。

## 9. 卡组展示版本

卡组不支持手动指定印刷版本。

系统自动选择展示版本：

```text
拥有的版本
    ↓
愿望单版本
    ↓
最新印刷版本
```

自动选择只决定卡组展示的卡图和印刷版本，不影响卡组记录。

选择版本时不考虑：

- 是否被其他卡组使用
- 所有卡组使用总数
- 当前卡组编辑数量
- 拥有数量是否足够
- 可用数量或分配数量

存在多个拥有版本或愿望版本时的同级选择规则，等待卡牌数据模型确认。

## 10. 卡组拥有数量

卡组中的实际拥有数量按逻辑卡牌汇总：

```text
所有 Set
+ 所有语言
+ 普通卡
+ 闪卡
```

每张卡计算：

- 当前卡组编辑数量
- 实际拥有数量
- 所有卡组编辑总数
- 使用该牌的卡组数量

## 11. 卡组异常状态

正常情况不显示状态。

异常状态互斥，只显示优先级最高的一项：

```text
数量不足
    ↓
被多个卡组占用
    ↓
正常无标识
```

### 11.1 数量不足

条件：

```text
当前卡组编辑数量 > 实际拥有数量
```

显示：

```text
数量不足 N
```

计算：

```text
N = 当前卡组编辑数量 - 实际拥有数量
```

### 11.2 被多个卡组占用

仅在当前卡组不存在“数量不足”时判断。

条件：

```text
使用该牌的卡组数量 > 1
且
所有卡组编辑总数 > 实际拥有数量
```

显示：

```text
被多个卡组占用 N
```

计算：

```text
N = 所有卡组编辑总数 - 实际拥有数量
```

### 11.3 判断顺序

```text
if 当前卡组数量 > 实际拥有数量
    显示「数量不足」
else if 使用卡组数 > 1
     且所有卡组数量 > 实际拥有数量
    显示「被多个卡组占用」
else
    不显示状态
```

### 11.4 示例

实际拥有 4 张：

| 当前卡组 | 所有卡组合计 | 使用卡组数 | 显示 |
| ---: | ---: | ---: | --- |
| 5 | 8 | 2 | `数量不足 1` |
| 4 | 8 | 2 | `被多个卡组占用 4` |
| 3 | 6 | 2 | `被多个卡组占用 2` |
| 2 | 4 | 2 | 不显示 |
| 4 | 4 | 1 | 不显示 |

异常状态不影响卡组保存和自动版本选择，不执行实体卡分配，只用于提示和统计。

## 12. 多卡组使用情况

卡牌详情或我的卡牌中展示逻辑卡牌的卡组使用情况：

```text
实际拥有：4
出现在 2 个卡组中
所有卡组编辑总数：8
跨卡组缺口：4
```

可以查看具体卡组：

```text
Burn：4
Modern Red：4
```

这属于统计，不代表具体实体卡已经分配给某个卡组。

## 13. 卡组统计

至少包括：

- 卡牌总数
- 不同逻辑卡牌数量
- 类型分布
- 颜色分布
- Mana Value 分布
- Mana Curve
- 土地与非地牌数量
- 数量不足的卡牌数量
- 被多个卡组占用的卡牌数量
- 总缺少数量
- 收藏满足率

具体统计字段以卡牌数据库提供的数据为准。

## 14. 操作日志

日志只记录以下 8 种操作：

```text
增加卡牌
减少卡牌
加入愿望单
移出愿望单
创建卡组
删除卡组
复制卡组
修改卡组
```

不记录普通查看和查询。

### 14.1 每日汇总

日志按日期分组。每天每种操作类型最多展示一条汇总记录：

```text
2026-09-24

增加卡牌    12
减少卡牌     3
加入愿望单   5
移出愿望单   1
创建卡组     1
删除卡组     1
复制卡组     2
修改卡组     4
```

当天没有发生的操作不显示。

### 14.2 卡牌操作明细

点击卡牌操作汇总，显示：

- 卡牌名
- 必要的 Set、收藏编号和语言
- 普通或闪卡
- 数量变化

示例：

```text
增加卡牌

Lightning Bolt · M11 · 英文 · 普通 +3
Lightning Bolt · M11 · 日文 · 闪卡 +1
Counterspell · 2X2 · 英文 · 普通 +2
```

愿望单明细：

```text
加入愿望单

Lightning Bolt · M11 · 日文
Counterspell · 2X2 · 英文
```

### 14.3 卡组操作明细

点击卡组操作汇总，只展示卡组名：

```text
修改卡组

Burn
Modern Red
Commander Atraxa
```

卡组重命名归入 `修改卡组`，只显示新名字，不显示旧名字。

同一次卡组修改无论调整多少张牌，都作为一次 `修改卡组` 操作，不展开卡组内部卡牌变化。

## 15. 明确不做

当前明确排除：

- 卡牌价格
- 交易记录
- 卡牌品相
- 逐张实体卡档案
- 复杂库存管理
- 卡组合法性校验
- 模拟起手
- 在线试抽或对战
- 批量导入导出
- 完整 Scryfall 搜索语法
- 手动指定卡组印刷版本
- 愿望单目标数量
- 愿望单闪卡偏好
- 愿望单备注
- 愿望单优先级
- 愿望单语言直接修改
- 卡牌详情说明语言切换
